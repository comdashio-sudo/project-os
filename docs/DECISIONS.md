# سجل القرارات

| الرقم | القرار | السبب | الأثر |
|---|---|---|---|
| ADR-001 | MySQL لكل البيئة الجديدة | طلب المستخدم الأخير يحدد MySQL بصورة صريحة. | تُنفذ صلاحيات العزل في API والمعاملات والفهارس النطاقية بدل PostgreSQL RLS. |
| ADR-002 | تطبيق مستقل بلا أصول DASHIO | حد غير قابل للتفاوض في المواصفة. | لا توجد قراءة أو إعادة استخدام أو اتصال بأي مورد منه. |
| ADR-003 | الاستحقاقات مفروضة خلفيًا | منع تجاوز واجهة المستخدم. | كل وحدة محمية بفحص خطة ودور ونطاق. |
| ADR-004 | محرك EVM نقي ومركزي | منع تكرار المعادلات وتسهيل اختبارها. | تتصل الواجهة بخدمة حسابات لا بمعادلات مضمنة. |
