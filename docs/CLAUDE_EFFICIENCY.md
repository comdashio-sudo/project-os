## 2. التحسينات المنفذة

1. **`scripts/state-brief.mjs`** — قارئ مختصر لـSTATE.md (قراءة فقط):
   - بلا خيارات: آخر 15 عنوانًا بأرقام أسطرها، وآخر قسم، وبنود `BLOCKED_BY_OWNER` المفتوحة في `OWNER_ACTIONS.md`.
   - `--grep <بند>`، `--section <سطر>`، `--since <commit>` (الأسطر المضافة فقط منذ آخر قراءة)، `--width`.
2. **`scripts/gates.mjs`** — يشغّل نفس أوامر البوابات (`pnpm check|build|test|test:db|coverage:trpc`) دون أي تغيير فيها، ويحفظ السجل الكامل في `node_modules/.cache/gates/<gate>.log`، ويطبع سطرًا واحدًا لكل بوابة مع ملخص vitest، وذيل السجل عند الفشل.
   - البوابة التي **نجحت** على الشجرة نفسها بالضبط (hash لـ`git write-tree` بعد إضافة التعديلات المتتبعة + قائمة الملفات غير المتتبعة) تُعرض `cached` ولا تُعاد. أي تعديل يُبطل ذلك، والفاشلة تُعاد دائمًا، و`--no-cache` يفرض الإعادة.
   - لا يلمس الـindex الحقيقي (يستعمل `GIT_INDEX_FILE` مؤقتًا).
3. **CLAUDE.md §1 و§9** — قراءة STATE بالأجزاء، عدم إعادة قراءة ما لم يتغير، تحديد الملفات قبل القراءة، البوابات بمخرَج مختصر، ضوابط الوكلاء الفرعيين، وتحديث STATE بقسم مختصر. لم تتغير أي قاعدة حاكمة أخرى.
