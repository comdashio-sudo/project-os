# دليل الدفعة 2.5 — استلام المواد (GRN)

**الحالة:** `PROVEN` محليًا قبل الالتزام. تضيف الدفعة سجل **Goods Receipt Note** واحدًا داخل تدفق المشتريات القائم، ولا تعيد استخدام انتقال أمر الشراء `received` بوصفه بديلًا عن كميات الاستلام. سجل GRN لا ينشئ حركة مخزون أو تكلفة فعلية أو أثر EVM ولا يحدّث قيمة أمر الشراء أو التزامه؛ تبقى هذه الآثار محجوزة صراحةً للدفعات 2.6 و2.7 و2.10.

| المتطلب | التنفيذ المثبت |
|---|---|
| سجل GRN | جدول `goods_receipt_notes` يحمل المستأجر والمشروع ورقم GRN الفريد في المشروع وأمر الشراء والمادة والكمية المقبولة والمرفوضة ووحدة القياس وتاريخ الاستلام والملاحظة ومنشئ السجل. السجل إنشائي فقط في هذه الدفعة؛ لا يوجد تعديل أو حذف تشغيلي. |
| أمر الشراء | يتطلب الخادم أمر شراء قائمًا من المستأجر والمشروع نفسيهما وحالته `issued` فقط. يرفض المعرف العابر أو الأمر غير الصادر من دون كشف بياناته. |
| المادة والوحدة | تتطلب المادة النشطة من المستأجر ووحدة مطابقة تمامًا لكتالوج المواد. تقبل الكمية المقبولة صفرًا أو موجبة والكمية المرفوضة صفرًا أو موجبة، بشرط أن يكون مجموعهما موجبًا. |
| رفض الجودة | عندما تكون الكمية المرفوضة موجبة، يفرض الخادم فحص جودة من المشروع نفسه حالته `accepted` ونتيجته `fail` أو `conditional`، وNCR مفتوحًا غير مغلق أو ملغى من المشروع نفسه. عند عدم وجود رفض يمنع تمرير هذين الرابطين، فلا تُسجل أدلة غير منطبقة. |
| الحراسة والتدقيق | القراءة تحت `PROJECT` و`project.read`، والإنشاء تحت `PROJECT` و`project.write` ونطاق المشروع بعد التحقق من العضوية. تكتب المعاملة سجل GRN وسجل `procurement.goods_receipt_note_created` مع مراجع الأمر والمادة والكمية والجودة وNCR في الذرة نفسها. |
| الواجهة | بطاقة Dashio ضمن مجموعة العقود والمشتريات في لوحة المشروع، بالعربية والإنجليزية. تعرض أوامر `issued` فقط، وتضبط وحدة المادة، ولا تظهر اختياري فحص الجودة وNCR إلا بعد إدخال كمية مرفوضة. لا تعرض راتبًا أو بيانات هوية أو تنشئ أمر شراء أو حركة مخزون. |
| الترحيل | `0043_fresh_red_ghost.sql` ينشئ الجدول والمفاتيح القصيرة والفهارس؛ روجع قبل التطبيق ولا يحمل حذفًا أو تعديلًا مدمرًا، ثم طُبق على MySQL/TiDB التشغيلي وأعاد `drizzle-kit generate` التحقق بلا فرق لاحق. |

## الدليل الحي والأتمتة

| الدليل | النتيجة |
|---|---|
| عزل أمر الشراء | يثبت المشغل رفض أمر شراء فعلي صادر في مستأجر/مشروع آخر عند محاولة إنشاء GRN للمشروع الحالي. |
| الاستحقاق | يعطل المشغل استحقاق `PROJECT` ويثبت رفض إنشاء GRN قبل الكتابة، ثم يعيده لمسار السماح. |
| أدلة الرفض | يثبت المشغل رفض كمية مرفوضة بلا فحص جودة وNCR، ثم ينشئ فحص `fail` مقبولًا وNCR مفتوحًا من المشروع نفسه ويقبل سجل GRN. |
| الأثر والقراءة | يعيد سجل GRN رقم الأمر ورقم المادة وكميتي 8.000 مقبولة و2.000 مرفوضة ورقم الفحص وNCR، مع أثر تدقيق واحد. يثبت الاستعلام أن حركات المستودع والتكاليف الفعلية بقيت صفرًا في سياق الدليل. |
| الواجهة | يثبت DOM اختيار أمر صادر ومادة وضبط `m3` وإظهار اختيارات الجودة/NCR عند رفض 2 وإرسال العقد المقيد؛ كما يثبت العرض العربي وغياب بيانات الراتب. |

> **الحد المقصود:** GRN في هذه الدفعة سجل استلام وجودة فقط. لا يحوّل الكمية المقبولة إلى رصيد، ولا يخصم التزامًا، ولا ينشئ تكلفة فعلية أو PV/EV/AC أو يغير حالة أمر الشراء. تنفيذ تلك الآثار مؤجل ومعلن للدفعات اللاحقة، ولا يجوز ادعاؤه من هذا السجل.
