# الحزم التجارية والاستحقاقات

| الحزمة | الوحدات المتاحة | حالة التشغيل |
|---|---|---|
| EXECUTIVE | Level 1 فقط مع النواة المشتركة اللازمة. | مستقل |
| PMO | Level 2 فقط مع بيانات ضوابط المشاريع الضرورية. | مستقل |
| PROJECT | Level 3 فقط مع النواة المشتركة اللازمة. | مستقل |
| EXECUTIVE + PMO | Level 1 وLevel 2 وتدفق بياناتهما. | متصل |
| PMO + PROJECT | Level 2 وLevel 3 وتدفق بياناتهما. | متصل |
| EXECUTIVE + PROJECT | Level 1 وLevel 3 ضمن حدود كل منتج. | متصل |
| ALL-IN-ONE | جميع مستويات المنصة. | متصل بالكامل |

يحكم الاستحقاق الواجهة وAPI والخدمة الخلفية، ولا يُعتبر ظهور المسار في قائمة التنقل تفويضًا كافيًا.
