# دليل الدفعة 3 — تدقيق مسارات الكتابة والمؤشرات وعقود tRPC

**الحالة:** `PROVEN` محليًا قبل الالتزام والدفع إلى `github/main`.

تنفذ هذه الدفعة تدقيقًا هندسيًا لمسارات الكتابة المصدّرة في طبقة الأعمال، وقابلية تتبع المؤشرات التشغيلية، وجرد عقود tRPC. لا تضيف مسار أعمال جديدًا ولا تغير صلاحية أو عزلًا أو نموذج بيانات.

| محور التدقيق | النتيجة المثبتة |
|---|---|
| مسارات الكتابة | حُصرت **88** دالة كتابة مصدّرة في `server/db.ts` ضمن أنماط create/transition/save/update/link/allocate/issue/transfer/record/capture/confirm. فُحصت مواضع المعاملات والتحديثات المقيدة بالنطاق، مع الرجوع إلى اختبارات الوصول والتكامل الحية للأثر. |
| منع النجاح الشكلي | لا يعالج المسار المدقق نجاح واجهة على أنه أثر أعمال: مسارات الكتابة المختبرة تقوم بتغيير سجل الأعمال ثم تكتب التدقيق في المعاملة نفسها، وتثبت اختبارات tRPC والتكامل الرفض قبل الإنشاء أو الانتقال العابر، والسماح مع أثر وتدقيق. لا تدعي هذه الدفعة اختبارًا يدويًا بشريًا لكل إجراء خارج المشغل. |
| جرد tRPC | `coverage:trpc` يسجل **177** إجراءً و**172** مرجع تكامل مباشر؛ الاستثناءات الخمسة هي إجراءات إطار محددة بالاسم (`access.check` و`auth.me` و`auth.logout` و`system.health` و`system.notifyOwner`). لا توجد إجراءات غير مصنفة أو استثناءات متقادمة. |
| قابلية تتبع PMO | يعرض مركز التخطيط القائم مسارًا لكل مشروع: `SPI = EV/PV` و`CPI = EV/AC`، وقيم EAC وVAC، وتاريخ لقطة EVM، ودرجة الصحة وتاريخها. يتحمل المسار اللقطات التاريخية التي لا تحمل EAC/VAC ويعرض المتاح بدل تعطل القسم. |
| العزل والتدقيق | أعاد مشغل MySQL/TiDB الحي إثبات **76/76** حالة؛ ويشمل رفض العزل والاستحقاق وآثار الكتابة وسجل التدقيق ضمن السيناريوهات الحاكمة. يبقى فحص منح التدقيق `approved: true`. |

## إصلاح قابلية التتبع

كانت شاشة PMO تعرض SPI وCPI والحالة والانحراف، وتوضح عتبات التنبيه، لكنها لم تجعل EAC/VAC وفترة لقطة EVM ودرجة/فترة الصحة مرئية معًا في مسار واحد للمراجع. أضيف **«Indicator source & formula / مصدر ومعادلة المؤشرات»** داخل مركز التخطيط نفسه، لا في شاشة مستقلة. يعرض المسار القيم والمعادلة وفترة المصدر، ولا يكتب أي أثر عند القراءة.

| حالة الاختبار | الإثبات |
|---|---|
| القيم والمعادلة | اختبار DOM يثبت ظهور `SPI = EV/PV · CPI = EV/AC` و`EAC 125.00; VAC -25.00` في مركز التخطيط نفسه. |
| توافق تاريخي | اختبار DOM القائم يثبت بقاء قائمة التخطيط قابلة للعرض عند وجود بيانات EVM أقدم بلا EAC/VAC. |
| عزل مصدر مستقل | اختبارات PMO تثبت بقاء التخطيط والسجلات متاحة عند فشل مصدر الاستثناءات أو مصدر المخاطر المستقل. |
