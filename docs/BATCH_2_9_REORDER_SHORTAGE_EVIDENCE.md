# دليل الدفعة 2.9 — حد إعادة الطلب ونقص المواد

**الحالة:** `PROVEN` محليًا قبل الالتزام والدفع إلى `github/main`.

تضيف الدفعة **إعداد حد إعادة الطلب** إلى تخصيص مادة داخل مشروع، وتحوّل نقص المادة إلى عنصر قراءة في مركز **«استثناءات اليوم»** الموجود في لوحة PMO. لا تنشئ الدفعة رصيدًا قابلًا للتحرير، أو جدول تنبيهات، أو شاشة تنبيهات مستقلة، أو أثر تدقيق ناتجًا عن القراءة.

| المتطلب | التنفيذ المثبت |
|---|---|
| تعريف الحد | الحقل الاختياري `project_material_overrides.reorderLevel` من نوع `decimal(18,3)`. يقبل الخادم رقمًا منتهيًا أكبر من صفر فقط، ويزيل الحد عند استقبال `null`. |
| مصدر الرصيد | يجمع مسار PMO قيم `warehouse_inventory_transactions.quantityDelta` لكل زوج مشروع/مادة عبر جميع مستودعات المشروع. لا يقرأ ولا يكتب جدول رصيد آخر. |
| تعريف النقص | يظهر الاستثناء فقط عندما يكون تخصيص المشروع نشطًا وله حد غير فارغ، ويكون رصيد المشروع المحسوب أقل من الحد. لا يظهر شيء عند غياب الحد أو تعطيل التخصيص أو وصول الرصيد إلى الحد أو تجاوزه. |
| الشدة والمعرّف | تكون الشدة `critical` عند رصيد صفر أو أقل و`warning` عند رصيد موجب دون الحد. المعرف ثابت: `inventory:{projectId}:{materialId}`. |
| النطاق والعزل | قراءة لوحة PMO تبقى تحت عضوية المستأجر واستحقاق PMO وصلاحية `pmo.read`. تحسب الخدمة العناصر للمشاريع التي أعادتها اللوحة فقط، وتقرأ overrides والحركات المقيدة بالمستأجر. لا يظهر مشروع أو مادة عابران. |
| الكتابة والتدقيق | الحفظ الإداري للـoverride فقط يكتب `materials.project_override_saved` في معاملته. لا تكتب قراءة مركز الاستثناءات سجل تدقيق أو صف تنبيه أو حركة مخزون. |
| الواجهة | حقل «حد إعادة الطلب / Reorder level» موجود في نموذج تخصيص المادة القائم، ويقبل الإزالة بتركه فارغًا. يظهر النقص مترجمًا داخل قائمة «استثناءات اليوم / Today’s exceptions» نفسها. |
| الترحيل | `0047_dizzy_loa.sql` يضيف العمود وحده. روجع وطُبق مسبقًا على MySQL/TiDB التشغيلي؛ أعاد `pnpm drizzle-kit generate` التحقق من عدم وجود فرق لاحق. |

## حالات الإثبات

| الحالة | الدليل |
|---|---|
| حد صالح وإزالة الحد | اختبار DOM لصفحة المواد يثبت إرسال `12.5` ثم `null` عند ترك الحقل فارغًا. |
| رسالة عربية آمنة | اختبار DOM يثبت منع قيمة الصفر محليًا برسالة عربية دون إظهار خطأ خادمي خام. |
| نقص وتحجيم الشدة | اختبار مجال يثبت `0/10` حرجًا و`2/8` تحذيرًا، ويستبعد `10/10`. |
| قائمة PMO القائمة | اختبار DOM يثبت «Material reorder required» وتفصيل `MAT-01 · Concrete · 2/10` داخل مركز اليوم القائم. |
| عزل واستحقاق وكتابة | التكامل الحي يرفض مشروعًا عابرًا وغياب استحقاق `PROJECT` قبل الحفظ، ثم يحفظ الحد ويسجل تدقيقًا واحدًا. |
| نقص مشتق بلا كتابة | التكامل الحي يثبت استثناء تحذيريًا عند `3/5` ثم حرجًا عند `0/5` بعد حركة صرف، ويثبت عدم زيادة تدقيق حفظ الحد بعد قراءتي PMO. |
| استبعاد مستأجر أجنبي | التكامل الحي ينشئ حدًا وحركة في المستأجر B ويثبت عدم ظهورهما في لوحة PMO للمستأجر A. |
