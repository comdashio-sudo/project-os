# صفحة الملف الشخصي — 24 سبتمبر 2026

## ما أُنجز

أضيف مسار `/profile` داخل PROJECT OS مع صفحة ملف شخصي متجاوبة بالعربية والإنجليزية. تعرض الصفحة اسم الحساب وبريده وصورته المختصرة، وتتيح تعديل الاسم الظاهر والمسمى الوظيفي والهاتف والموقع والنبذة المهنية. أضيف رابط الصفحة إلى قائمة المستخدم في الملاحة المؤسسية.

وتتضمن الصفحة مركزًا لمهام المتابعة الشخصية يستطيع مدير المشروع من خلاله إضافة مهمة، وربطها باسم مشروع أو نطاق، وتحديد تاريخ استحقاق، ثم نقلها بين الحالات: مفتوحة، قيد التنفيذ، ومكتملة، أو حذفها. تظهر عدادات الحالات الثلاث لتسريع المتابعة اليومية.

## الحوكمة ومصدر البيانات

لا تسمح الصفحة للمستخدم بتعديل دوره أو صلاحياته. يعرض قسم الأدوار والصلاحيات حالة صريحة عندما لا تكون عضوية المستأجر ونطاق المشروع محملين في الجلسة، بدل اختلاق دور أو صلاحية. مصدر الأدوار المعتمد هو عضويات المستأجر وإسنادات النطاق، وليس ما يكتبه المستخدم في ملفه.

بيانات الملف الشخصي وقائمة مهام المتابعة في هذه النسخة تُحفظ محليًا في متصفح المستخدم عبر `localStorage`. يظهر هذا القيد للمستخدم داخل الواجهة بوضوح. لذلك لا تُعامل المهام المحلية كسجل تشغيلي للمشروع، ولا تدخل في EVM أو KPI أو التدقيق. ربطها لاحقًا بسجل مهام خادمي يحتاج قرارًا ومخططًا مستقلين لمصدر المهمة ومالكها ونطاقها وتدقيقها، ولا يُفترض تلقائيًا.
