# خطة ترحيل 0012 — الموارد والقدرة

ينشئ الترحيل سجل `project_resources` للموارد المخططة للمشروع، مع مستأجر ومشروع إلزاميين، رمز فريد داخل المشروع، نوع المورد، وحدات مخططة ومخصصة، وتكلفة وحدية. لا يمثل السجل ساعات فعلية أو كشف رواتب؛ بل قدرة تشغيلية معلنة للمشروع.

| القيد | التطبيق |
|---|---|
| العزل | مفاتيح أجنبية للمستأجر والمشروع، وفهرس نطاق `tenantId, projectId`. |
| الفرادة | رمز المورد فريد داخل المشروع فقط. |
| القدرة | يمنع API القيم السالبة، ويعرض الفرق بين الوحدات المخططة والمخصصة. |
| التدقيق | تنشأ الكتابة والسجل التدقيقي من الخادم داخل معاملة واحدة. |

بعد توليد SQL، يراجع الجدول والفهارس والمفاتيح، ثم يطبق الترحيل ويتحقق من وجود `project_resources` وفهرس النطاق. قبل وجود بيانات يكون الاسترجاع حذف الجدول؛ وبعدها ينفذ ترحيل علاجي فقط دون حذف تشغيلي.
