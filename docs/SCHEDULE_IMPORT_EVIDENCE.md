# دليل الاستيراد الزمني المحكوم — Excel وXER

**الحالة:** `PROVEN` قبل الالتزام. يوسّع هذا العمل محرك الاستيراد القائم، ولا يضيف قناة رفع أو نموذج مهام موازٍ. لا يكتب النظام WBS أو نشاطًا قبل التحليل الخادمي والمعاينة والتأكيد الصريح وإعادة التحقق من البصمة.

| البند | التنفيذ المثبت |
|---|---|
| قالب Excel `schedule_v1` | يقبل ورقة XLSX واحدة فقط، فيها `Record Type` و`WBS Code` مع حقول WBS أو النشاط المعتمدة. صف WBS يتطلب الرمز والاسم؛ وصف النشاط يتطلب WBS والرمز والاسم والبداية والنهاية. يرفض العمود غير المعتمد أو الرمز المكرر أو نوع السجل غير الصحيح أو تاريخ نهاية يسبق البداية أو مرجع WBS غير المحلول. توفر الواجهة قالب XLSX فعليًا، لا ملف CSV مسمى خطأً. |
| XER المحافظ | يقبل محلل XER جدولي Primavera `PROJWBS` و`TASK` فقط؛ يستخرج WBS والنشاط وتواريخهما وحالتهما وقيمتهما المخططة. يرفض غياب أي من الجدولين، كما يرفض أي جدول XER إضافي بدل تجاهله أو استيراد مجموعة جزئية بصمت. هذه حدود مقصودة: ملف P6 متعدد الجداول لا يصبح مقبولًا إلا بعد توسيع قالب خادمي ودليله، ولا يُحوّل إلى قبول عام. |
| المعاينة والتأكيد | يحفظ الأصل في التخزين الكائني ومفتاحه وSHA-256 في `data_imports`. يعيد التأكيد تنزيل الأصل، ويطابق البصمة، ويعيد التحليل قبل الكتابة. لا يصبح السجل قابلاً للتأكيد عند وجود أي خطأ. |
| الذرية والتكرار | تنفذ المعاملة WBS قبل الأنشطة، وتحل النشاط إلى WBS الذي أنشئ أو وجد في المشروع نفسه. تطبق سياسات التكرار المحفوظة لكل من رموز WBS والأنشطة، وتحفظ نتائج الصفوف والعدادات وسجل `data_import_completed` في المعاملة نفسها. |
| الحراسة | التحليل والتأكيد يتطلبان عضوية المستأجر، ومنتج `PROJECT`، وميزة `DATA_IMPORT`، وصلاحية `project.write`، وملكية المشروع. يرفض المسار المشروع أو المستأجر العابر وغياب استحقاق PROJECT قبل أي رفع أو كتابة تشغيلية. |
| الواجهة | يضيف `ProjectImports` خيار «الجدول الزمني / Schedule» ويعرض الحقول المعتمدة وقالب XLSX وتعليمات XER بالعربية والإنجليزية، ويقيد اختيار الملف إلى `.xlsx,.xer` لهذا القالب. تترجم أخطاء XER والتاريخ وWBS والحالة؛ لا تعرض رمز خادم خامًا للحالات الجديدة. |
| المخطط | يوسّع الترحيل `0040_organic_arclight.sql` تعداد `data_imports.sourceFormat` إلى `xlsx/csv/xer` فقط، وقد طبق على MySQL/TiDB التشغيلي. أضاف الدليل الحي التوسعة نفسها إلى قاعدة التكامل المعزولة. |
