# خطة ترحيل 0021 — سجل فحوصات الجودة

## الهدف

يضيف الترحيل جدول `quality_inspections` لتوثيق فحوصات الجودة داخل مشروع معزول. يحمل كل سجل مفتاح المستأجر والمشروع والمنشئ ورقم فحص فريدًا داخل المشروع، ونوع الفحص، وتاريخ الفحص، والنتيجة، والملخص، وحالة دورة العمل.

## الأثر المتوقع

| العملية | الأثر المتوقع |
|---|---|
| إنشاء الجدول | إضافة غير هدمية لجدول تشغيلي جديد فقط. |
| المفاتيح الخارجية | منع فحص بلا مستأجر أو مشروع أو منشئ صالح. |
| الفريدة | منع رقم فحص مكرر داخل المشروع مع السماح به في مشروع آخر. |
| فهرس القراءة | تسريع سجل فحوصات المشروع حسب التاريخ والحالة. |

## استعلام التحقق

```sql
SELECT table_name
FROM information_schema.tables
WHERE table_schema = DATABASE()
  AND table_name = 'quality_inspections';
```

## الاسترجاع

لا ينفذ حذفًا تلقائيًا. قبل وجود بيانات تشغيلية معتمدة يمكن الرجوع إلى نقطة التحقق السابقة. بعد الاستخدام يتطلب إسقاط الجدول قرار صيانة مستقل لأنه يهدم دليل الجودة.

## الحدود

لا يربط هذا الترحيل فحص الجودة بسجل NCR أو WBS تلقائيًا، ولا ينشئ مرفقًا أو إشعارًا خارجيًا. تبقى تلك التكاملات دفعات لاحقة بحراسة نطاق مستقلة.
