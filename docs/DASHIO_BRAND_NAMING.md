# قاعدة تسمية هوية Dashio وPROJECT OS

## القرار

**Dashio** هي العلامة البصرية الأساسية والاسم الذي يظهر في الشعارات والرؤوس العامة ونقاط الدخول. أما **PROJECT OS** فهو اسم المنصة الوصفي، ويجوز ظهوره في سياقات المنتج أو الحوكمة أو وثائق النظام حين يزيل اللبس عن مجال العمل. لا يمثل ظهور اسم المنصة انتقالًا إلى علامة أخرى، ولا يسمح بخلط أي مورد أو هوية أو نشر تابع لـTASLEEM.

| السياق | المعروض المعتمد | القاعدة |
|---|---|---|
| الرأس العام، الصفحة الرئيسية، وشاشة الدخول | شعار Dashio الرسمي | لا يستخدم رمز بديل أو placeholder أو شعار PROJECT OS القديم. |
| رأس وحدة مستقلة مثل EVM | شعار Dashio الرسمي مع تسمية الوحدة | لا يستخدم رمز حرفي أو رأس يحمل PROJECT OS وحده. |
| نص تعريف المنصة أو سياق تشغيلي داخلي | `PROJECT OS` أو `Dashio Project OS` | يبقى الاسم الوصفي مسموحًا ما دام لا يحل محل علامة Dashio أو يوحي بمنتج مستقل. |
| لوحات EXECUTIVE وPMO وLicensing | تسمية المنتج النصية `PROJECT OS` داخل سياق تشغيل محدد | تعد تسمية نطاق المنتج، لا شعارًا؛ تعتمد الهوية البصرية المحيطة وتوكنات Dashio. |

> لا تعتبر المطابقة النصية لعبارة `PROJECT OS` وحدها عيبًا بصريًا. العيب هو عرضها كبديل وحيد للشعار الرسمي في رأس عام أو نقطة دخول، وهو ما عولج في شاشة EVM واختبر بصريًا.

## دليل المراجعة

أظهر تدقيق الشيفرة بقايا نصية في `ExecutiveDashboard.tsx` و`PmoDashboard.tsx` و`LicensingConsole.tsx`. بعد المراجعة صنفت كتسميات نطاق منتج ضمن لوحات محمية، لا كأصول شعار أو placeholders. تظل شاشة EVM حالة مختلفة لأنها كانت تعرض رمزًا حرفيًا ورأسًا عامًا لـPROJECT OS؛ لذلك استبدلت بعلامة Dashio الرسمية واختبرت بالعربية والإنجليزية وعلى سطح المكتب والجوال.
