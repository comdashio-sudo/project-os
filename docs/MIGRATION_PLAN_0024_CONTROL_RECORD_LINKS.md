# خطة ترحيل 0024 — روابط سجلات الضوابط

## الهدف

يضيف الترحيل سجلًا موحدًا لربط المخاطر والقضايا والإجراءات والقرارات ضمن مشروع واحد. يسمح السجل بتمثيل علاقة عملية مثل «مخاطرة مرتبطة بإجراء تخفيف» أو «قضية مرتبطة بقرار»، مع مصدر وهدف من الأنواع التشغيلية الأربعة فقط.

## الضوابط

| القيد | موضع الفرض |
|---|---|
| عزل المستأجر والمشروع | مفاتيح `tenantId` و`projectId` وفهرس قراءة، ثم تحقق خادمي من ملكية المصدر والهدف. |
| نوع الرابط | `risk` أو `issue` أو `action` أو `decision` فقط في قاعدة البيانات والعقد. |
| منع الرابط الذاتي | الخادم يرفض المصدر والهدف المتطابقين. |
| منع تكرار العلاقة | فهرس فريد للمشروع ونوع ومعرّف المصدر والهدف. |
| عدم اليتم | لا يمكن لقاعدة البيانات إنشاء مفتاح أجنبي متعدد الأشكال؛ لذلك يعيد الخادم اختيار كل سجل بنطاق المستأجر والمشروع قبل المعاملة. |

## الأثر والاسترجاع

الترحيل إضافة غير هدمية لجدول واحد وعلاقته بالمستأجر والمشروع والمنشئ. بعد حفظ رابط تشغيلي لا يُسقط الجدول إلا ضمن صيانة معتمدة، لأن ذلك يهدم أثر الحوكمة والتدقيق.

## استعلام التحقق

```sql
SELECT table_name, column_name
FROM information_schema.columns
WHERE table_schema = DATABASE()
  AND table_name = 'control_record_links';
```
