# دليل تحسين مسارات الوصول التشغيلي

**الحالة:** `PROVEN` محليًا قبل الالتزام والدفع إلى `github/main`.

يهدف التحسين إلى تقليل زمن الوصول إلى المعلومة أو المشروع الصحيح، من دون إنشاء نسخة ثانية من البيانات أو نسخ حراسة الصلاحيات إلى الواجهة. يعرض النظام طريقين متكاملين للوصول: الملاحة المؤسسية القابلة للبحث التي لا تعرض إلا الوحدات المحسوبة خادميًا، والبحث الموضعي في سجل المشاريع الذي يرشح فقط المشاريع التي أعادها استعلام السجل المصرح به.

| نقطة الوصول | السلوك المحكوم |
|---|---|
| الملاحة المؤسسية | تبقى قائمة الوحدات والبحث الجانبي معتمدة حصريًا على `navigation.get` المحسوب خادميًا؛ لا يعرض الحساب منخفض الصلاحية روابط EXECUTIVE أو PMO أو سجل المشاريع أو إدارة المستأجر. |
| سجل المشاريع | يتيح حقلًا واحدًا للبحث بالرمز أو الاسم أو النوع أو مرحلة دورة الحياة، ويعرض عدد النتائج ويتيح مسح البحث. لا يجلب البحث سجلات إضافية؛ يرشح فقط نتيجة `projects.list` الموجودة مسبقًا ضمن المستأجر المصرح. |
| مركز قيادة المشروع | يبقى المدخل المباشر من بطاقة المشروع إلى مركز القيادة، حيث تجمع بطاقات الأداء ومسارات الجدولة والتجاري والموقع والضمان المعلومات والإجراءات في السياق نفسه، مع بقاء كل كتابة تحت عقدها الخادمي. |
| تعدد المسارات | يستطيع المستخدم الوصول إلى المشروع من سجل المشاريع أو الوصول إلى الوحدات المرخصة من الملاحة القابلة للبحث؛ ولا يحل أي مسار واجهة محل تحقق الخادم عند فتح الوجهة أو تنفيذ الإجراء. |

## نتائج التدقيق

| الدور/السياق | نتيجة التدقيق |
|---|---|
| EXECUTIVE | ملاحة مؤسسية مرخصة ولوحة قرار مستقلة؛ لا تضيف هذه الدفعة روابط إدارية أو عملياتية غير مصرح بها. |
| PMO | قائمة وحدات محسوبة خادميًا وبحث جانبي في العناصر المرخصة؛ مركز التخطيط والاستثناءات يظل مصدر المتابعة متعددة المشاريع. |
| PROJECT | سجل قابل للبحث للوصول الأسرع إلى المشروع، ثم مركز قيادة يفتح مسارات الجدولة والتجاري والموقع والضمان من السياق نفسه. |
| حساب منخفض الصلاحية | لا تضيف الواجهة أي نتيجة أو رابطًا لا يعود من الاستعلام المرخص؛ تثبت اختبارات الملاحة غياب الروابط المميزة عند خلو نتيجة الخادم. |

## حدود معلنة

هذا تحسين وصول واكتشاف، لا نظام بحث شامل في قاعدة البيانات ولا بديل عن حراس RBAC أو نطاق المستأجر والمشروع. لا يعالج القبول اليدوي للأدوار أو قارئات الشاشة؛ وتبقى هذه القيود موثقة في `STATE.md` ولا يحول البناء الأخضر إلى حكم Pilot أو إنتاج.
