# خطة ترحيل 0013 — سجل المطالبات التعاقدية

ينشئ الترحيل جدول `claims` لمطالبات مرتبطة بمستأجر ومشروع، مع ارتباط اختياري بعقد داخل المشروع نفسه يتحقق منه الخادم. يحتوي السجل رقم مطالبة فريدًا داخل المشروع، عنوانًا ووصفًا، قيمة مطلوبة وقيمة معتمدة، عملة، وحالة محكومة.

| القيد | التطبيق |
|---|---|
| العزل | `tenantId` و`projectId` إلزاميان بمفاتيح أجنبية وفهرس نطاق. |
| الربط التعاقدي | `contractId` اختياري؛ يتحقق الخادم من أنه ضمن المستأجر والمشروع قبل الكتابة. |
| الفرادة | `claimNumber` فريد داخل المشروع. |
| القيم | ترفض API المبالغ السالبة؛ لا يجوز أن تتجاوز القيمة المعتمدة القيمة المطلوبة عند اعتمادها. |
| الدورة | `draft → submitted → under_review → approved/rejected/withdrawn` مع انتقالات خادمية فقط. |
| التدقيق | ينشأ السجل والانتقال وسجل التدقيق من الخادم داخل معاملات منفصلة حسب العملية. |

بعد التوليد يراجع SQL للتأكد من عدم وجود حذف أو تغيير مدمر، ثم يطبق على التشغيل وقاعدة التكامل ويُتحقق من الجدول والفهرس. قبل وجود بيانات يمكن الاسترجاع بحذف الجدول؛ بعد الاستخدام ينفذ ترحيل علاجي غير مدمر فقط.
