# تصميم مصدر NCR المتأخر لصحة المشروع

يمتلك محرك صحة المشروع قاعدة `OVERDUE_NCR` وخصمًا محددًا عند وجود عدم مطابقة متأخر. تستبدل هذه الدفعة مصدره الصفرى المؤقت بسجل `ncrs` التشغيلي، دون تعديل أوزان المحرك أو عتبات الحالة.

| معيار العد | القاعدة |
|---|---|
| العزل | يطابق الاستعلام `tenantId` و`projectId` من لقطة الصحة |
| الاستحقاق | يكون `dueAt` موجودًا وأسبق من وقت الخادم عند الالتقاط |
| الانفتاح | تستبعد حالتا `closed` و`cancelled` فقط؛ يبقى NCR مفتوحًا حتى إغلاق رسمي |
| الأثر | يمرر العداد إلى `overdueNcrCount` ويحفظ في مصادر اللقطة والتدقيق |

لا يقبل العميل العداد أو وقت القطع. يثبت الاختبار احتساب NCR متأخر مخوّل واستبعاد سجل خارج المشروع، وتعرض بطاقة Level 3 العداد بالعربية والإنجليزية من اللقطة الحالية أو المخزنة.
