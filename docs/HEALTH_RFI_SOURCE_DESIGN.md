# تصميم مصدر RFI المتأخر لصحة المشروع

محرك صحة المشروع يحتوي أصلًا على قاعدة `OVERDUE_RFI` وخصم ثماني نقاط عند وجود طلب معلومات متأخر. تتولى هذه الدفعة استبدال قيمة المصدر الصفرية المؤقتة بعد إنشاء سجل RFI بمصدر تشغيلي فعلي دون تغيير معادلة الصحة أو شدتها.

| معيار العد | القاعدة |
|---|---|
| ملكية السجل | يطابق `tenantId` و`projectId` المطلوبين في الالتقاط |
| الاستحقاق | `dueAt` غير فارغ وأسبق من وقت القطع الذي يمرره الخادم |
| الانفتاح | تستبعد حالتا `closed` و`cancelled` فقط؛ وتبقى الحالات الأخرى مفتوحة حتى إغلاق رسمي |
| الأثر | يمرر العدد إلى `overdueRfiCount` ثم يحتفظ ضمن `sources` في لقطة الصحة |

لا يقبل العميل العدد أو وقت الخادم؛ يحسبهما المسار من قاعدة البيانات ووقت القطع المحمي. يجب أن يثبت الاختبار أن استعلام المصدر مقيد بالمستأجر والمشروع وأن العداد يظهر في Level 3 بالعربية والإنجليزية.
