# أمن PROJECT OS

## الضوابط الإلزامية

تعتمد المنصة التحقق من الجلسة على الخادم، وRBAC، وفحص الاستحقاقات، والتحقق من المدخلات عبر Zod، وسجل تدقيق للعمليات المؤثرة. لا يُخزن أي سر خدمة أو كلمة مرور في العميل.

## مصفوفة الاختبار الأمني

| الاختبار | معيار النجاح |
|---|---|
| عزل المستأجرين | لا يمكن لعضو من شركة قراءة أو تعديل سجل شركة أخرى. |
| IDOR | لا يسمح تبديل معرّف الكيان بتجاوز العضوية أو نطاق المشروع. |
| تجاوز الأدوار | لا تصل الأدوار الأدنى إلى وظائف الإدارة أو الحوكمة المحمية. |
| تجاوز الاستحقاق | لا تنجح واجهة API لوحدة غير مرخّصة حتى مع طلب مباشر. |
| التخزين | لا يصدر رابط ملف قبل تفويض المستأجر والعضوية. |


## الدخول بكلمة المرور (D-82، 2026-11-09)

- طريقتا دخول من الشاشة نفسها: رمز البريد، أو كلمة مرور يحفظها Supabase Auth وحده (`/token?grant_type=password`). لا تُخزَّن الكلمة ولا تُسجَّل ولا تُعاد في خطأ عندنا؛ والسجل يحمل اسم الخطأ وإطاراته لا رسالته.
- «تعيين كلمة مرور» و«نسيت كلمة المرور» مسار واحد: رمز من `/api/auth/email/request` ثم `/api/auth/password/set` (يتحقق `/verify` ثم `PUT /user` بجلسة ذلك الرمز ثم `/logout`). لا روابط استعادة، ولا `service_role`.
- رد واحد (`401 PROJECT_OS_AUTH_CREDENTIALS_INVALID`) لكلمة خاطئة ولبريد غير معروف أو غير مدعو أو غير مؤكد: لا تعداد للحسابات.
- خمس كلمات خاطئة في 15 دقيقة تقفل البريد 15 دقيقة (`429` و`retryAfterSeconds`)، يُفحص القفل قبل سؤال Supabase فالكلمة الصحيحة لا تفتحه، وفوقه حد مصدر العنوان. عدّاد الكلمات منفصل عن عدّاد الرموز.
- الحد الأدنى 8 أحرف (والأقصى 72، ما يقرؤه bcrypt). والدخول بالكلمة ينتهي بالجلسة نفسها، فالتحقق بخطوتين (D-81) يُطبَّق بعده كما بعد الرمز.
## التخزين داخل قاعدة البيانات (D-79، 2026-11-10)

- حين تغيب متغيرات S3 الخمسة تُحفظ الملفات في `stored_files` (حتى 5 MB للملف بقيد CHECK، و100 MB للشركة بقفل استشاري يمنع السباق). الصف ملك الشركة المسمّاة في مفتاحه، وRLS تحجبه عن غيرها؛ المنح لـ`project_os_app` وحده، ولا سياسة لـ`anon`.
- «الرابط الموقّع» `/api/storage/file/<token>` و«رابط الرفع» `PUT /api/storage/upload/<token>`: رمز HS256 بمفتاح مشتق من سر الكوكي، لمفتاح واحد ولعملية واحدة، 15 دقيقة، يُسكّ فقط بعد فحوص صلاحية المستدعي (كرابط S3 الموقّع). التقديم بـ`nosniff` و`Content-Security-Policy: … sandbox`: ملف SVG مرفوع لا يشغّل شيئًا من هذا المسار.
