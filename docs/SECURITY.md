# أمن PROJECT OS

## الضوابط الإلزامية

تعتمد المنصة التحقق من الجلسة على الخادم، وRBAC، وفحص الاستحقاقات، والتحقق من المدخلات عبر Zod، وسجل تدقيق للعمليات المؤثرة. لا يُخزن أي سر خدمة أو كلمة مرور في العميل.

## مصفوفة الاختبار الأمني

| الاختبار | معيار النجاح |
|---|---|
| عزل المستأجرين | لا يمكن لعضو من شركة قراءة أو تعديل سجل شركة أخرى. |
| IDOR | لا يسمح تبديل معرّف الكيان بتجاوز العضوية أو نطاق المشروع. |
| تجاوز الأدوار | لا تصل الأدوار الأدنى إلى وظائف الإدارة أو الحوكمة المحمية. |
| تجاوز الاستحقاق | لا تنجح واجهة API لوحدة غير مرخّصة حتى مع طلب مباشر. |
| التخزين | لا يصدر رابط ملف قبل تفويض المستأجر والعضوية. |
