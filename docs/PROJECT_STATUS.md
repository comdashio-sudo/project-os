# حالة مشروع PROJECT OS

| الحقل | الحالة الحالية |
|---|---|
| المرحلة الحالية | Phase 2 — سجلات التحكم والحوكمة، بعد تأسيس النواة متعددة المستأجرين ومستويات Level 1–3 |
| الوحدة الحالية | سجل PMO للمخاطر والقضايا، مع إجراءات وقرارات محمية قيد استكمال الواجهات |
| أعمال مكتملة | تدقيق مستقل، مستودع GitHub خاص مستقل، توثيق البداية، مخطط الشركات والعضويات والأدوار والصلاحيات والاشتراكات والاستحقاقات وسجل التدقيق، ترحيلات ضوابط المشروع، إنشاء مساحة مستأجر فعلي، حاسبة EVM مركزية، محرك صحة المشروع، إجراءات المشاريع ولقطات EVM المحمية، وحارس WBS موحد لمسارات الميزانية والتكلفة والتقدم. أضيفت شاشة Level 3 محمية، ولوحتا Level 1 وLevel 2 بقراءات مقيّدة بالاستحقاق، وسجل PMO تفاعلي ثنائي اللغة للمخاطر والقضايا. كما أضيفت مسارات إنشاء الإجراءات والقرارات مع فحص استحقاق ونطاق المشروع وكتابة تدقيقية ذرية. |
| العمل الجاري | إكمال واجهات الإجراءات والقرارات، وإضافة اختبارات السماح والرفض لهذه المسارات، ثم تجهيز اختبار تكامل فعلي بقاعدة اختبارية مستقلة. |
| التعريب | طبقة لغة مركزية تضبط `lang` و`dir` وتحفظ الاختيار؛ زر اللغة حاضر في رؤوس الواجهات. تضيف طبقة API رموز أخطاء ورسائل آمنة بالعربية والإنجليزية، وتعرض مساحة العمل وسجل المشاريع وحاسبة EVM الرسالة بحسب اللغة الحالية. |
| الاختبارات الفاشلة | لا توجد؛ نجح 28 اختبارًا ضمن ستة ملفات، وفحص TypeScript والبناء الإنتاجي في آخر تحقق مكتمل. |
| المشكلات المثبتة | أصلح توافق تجميع `Set`، وبنية JSX لمساحة العمل، وفحص نطاق WBS العابر للمشروع، وإظهار رسائل الخادم الخام في واجهات التشغيل. |
| العمل المعلق | اختبار تكامل حقيقي لقاعدة البيانات مستقلة عن المحاكاة، اختبارات السماح التشغيلية، تجميع PV/EV/AC الفعلي من السجلات، الجدولة والأنشطة، واجهات الإجراءات والقرارات، والمستندات وسير العمل. |
| ترحيلات قاعدة البيانات | `0001_public_gamma_corps.sql` و`0002_violet_scrambler.sql` و`0003_silly_unicorn.sql` مطبقة بنجاح. لا يمكن فرض مشغلي منع تعديل/حذف سجل التدقيق في TiDB Serverless لأن المشغلات غير مدعومة؛ الفجوة موثقة. |
| حالة النشر | النشر التلقائي مفعّل عند كل نقطة تحقق؛ آخر نسخة منشورة هي `c1518462`. |
| الإجراء التالي الدقيق | ربط واجهة القيادة التنفيذية بإنشاء القرار، وإضافة واجهة إجراء PMO، ثم كتابة اختبارات السماح والرفض لمسارات السجلات الأربعة. |
