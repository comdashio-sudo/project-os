# حالة مشروع PROJECT OS

| الحقل | الحالة الحالية |
|---|---|
| المرحلة الحالية | Phase 1 — النواة متعددة المستأجرين والاستحقاقات، مع دفعة Level 3 أولى منجزة |
| الوحدة الحالية | حراسة نطاق المشروع/WBS، رسائل الأخطاء الثنائية، وواجهة إدخال Level 3 |
| أعمال مكتملة | تدقيق مستقل، مستودع GitHub خاص مستقل، توثيق البداية، مخطط الشركات والعضويات والأدوار والصلاحيات والاشتراكات والاستحقاقات وسجل التدقيق، ترحيلات ضوابط المشروع، إنشاء مساحة مستأجر فعلي، حاسبة EVM مركزية، محرك صحة المشروع، إجراءات المشاريع ولقطات EVM المحمية، وحارس WBS موحد لمسارات الميزانية والتكلفة والتقدم. أضيفت شاشة Level 3 محمية تقرأ بيانات المشروع وتدخل WBS وبنود الميزانية والتكلفة الفعلية والتقدم وتحفظ لقطة EVM، مع سجلات تدقيق ذرية لهذه الكتابات. |
| العمل الجاري | استكمال نماذج السماح والاختبارات التكاملية بقاعدة اختبارية مستقلة، ثم توسيع وحدات المخاطر والقضايا والإجراءات. أضيفت الآن لوحتا Level 1 وLevel 2 بقراءات محمية حسب استحقاق EXECUTIVE أو PMO. |
| التعريب | طبقة لغة مركزية تضبط `lang` و`dir` وتحفظ الاختيار؛ زر اللغة حاضر في رؤوس الواجهات. تضيف طبقة API رموز أخطاء ورسائل آمنة بالعربية والإنجليزية، وتعرض مساحة العمل وسجل المشاريع وحاسبة EVM الرسالة بحسب اللغة الحالية. |
| الاختبارات الفاشلة | لا توجد؛ نجح 28 اختبارًا ضمن ستة ملفات، وفحص TypeScript والبناء الإنتاجي في آخر تحقق مكتمل قبل إضافة واجهة Level 3. |
| المشكلات المثبتة | أصلح توافق تجميع `Set`، وبنية JSX لمساحة العمل، وفحص نطاق WBS العابر للمشروع، وإظهار رسائل الخادم الخام في واجهات التشغيل. |
| العمل المعلق | اختبار تكامل حقيقي لقاعدة البيانات مستقلة عن المحاكاة، اختبارات السماح التشغيلية، تجميع PV/EV/AC الفعلي من السجلات، الجدولة والأنشطة، Level 1 وLevel 2، والمستندات وسير العمل. |
| ترحيلات قاعدة البيانات | `0001_public_gamma_corps.sql` و`0002_violet_scrambler.sql` و`0003_silly_unicorn.sql` مطبقة بنجاح. لا يمكن فرض مشغلي منع تعديل/حذف سجل التدقيق في TiDB Serverless لأن المشغلات غير مدعومة؛ الفجوة موثقة. |
| حالة النشر | النشر التلقائي مفعّل عند حفظ نقطة تحقق؛ لم تحفظ دفعة Level 3 الجديدة بعد. |
| الإجراء التالي الدقيق | إضافة سجلات المخاطر والقضايا والإجراءات وواجهاتها، ثم تجهيز قاعدة اختبار تكامل مستقلة تثبت مسارات السماح والرفض الفعلية. |
