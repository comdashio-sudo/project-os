| الحقل | الحالة الحالية |
|---|---|
| المرحلة الحالية | Phase 1 — النواة متعددة المستأجرين والاستحقاقات |
| الوحدة الحالية | مخطط الهوية والصلاحيات والاستحقاقات |
| أعمال مكتملة | تدقيق مستقل، مستودع GitHub خاص مستقل، توثيق البداية، مخطط الشركات والعضويات والأدوار والصلاحيات والاشتراكات والاستحقاقات وسجل التدقيق، ترحيل النواة، وخدمة تفويض أولية قابلة للاختبار. |
