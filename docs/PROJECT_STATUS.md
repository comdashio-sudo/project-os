# حالة مشروع PROJECT OS

| الحقل | الحالة الحالية |
|---|---|
| المرحلة الحالية | Phase 2 — سجلات التحكم والحوكمة، بعد تأسيس النواة متعددة المستأجرين ومستويات Level 1–3 |
| الوحدة الحالية | إدارة المستأجرين؛ اكتمل اختيار مستخدم موجود عبر بحث بالبريد مطابق ومحدود ثم إسناد دور ونطاق بصورة ذرية. البحث محمي بعضوية فعالة وحزمة EXECUTIVE وصلاحية `tenant.manage`، ولا يعيد مستخدمًا لديه عضوية قائمة ضمن المؤسسة. تبقى دعوات البريد وإدارة إنشاء/تحديث/إلغاء الأدوار والنطاقات المتقدمة ضمن نطاقات لاحقة. |
| أعمال مكتملة | تدقيق مستقل، مستودع GitHub خاص مستقل، توثيق البداية، مخطط الشركات والعضويات والأدوار والصلاحيات والاشتراكات والاستحقاقات وسجل التدقيق، ترحيلات ضوابط المشروع، إنشاء مساحة مستأجر فعلي، حاسبة EVM مركزية، محرك صحة المشروع، إجراءات المشاريع ولقطات EVM المحمية، وحارس WBS موحد لمسارات الميزانية والتكلفة والتقدم. أضيفت شاشة Level 3 محمية، ولوحتا Level 1 وLevel 2 بقراءات مقيّدة بالاستحقاق، وسجل PMO تفاعلي ثنائي اللغة للمخاطر والقضايا والإجراءات. كما أضيفت مسارات إنشاء المخاطر والقضايا والإجراءات والقرارات مع فحص استحقاق ونطاق المشروع وكتابة تدقيقية ذرية. نموذج الإجراء يعرض الإجراءات غير المكتملة وغير الملغاة فقط، مع ترجمة الأولويات، وحقل عدد الإجراءات المفتوحة. كما أُصلحت رسالة حفظ القرار التنفيذي وحالة غياب المشاريع. وتضمن Level 3 الآن سجلًا للأنشطة بقراءة محمية ضمن المشروع، وإنشاء محمي بحزمة PROJECT وصلاحية `project.write` ونطاق المشروع، وربط WBS اختياريًا يتحقق من النطاق، ورفض تاريخ نهاية يسبق البداية، وكتابة تدقيقية ذرية. كما يتيح مسار EVM المحسوب تجميع PV وEV وAC وBAC من مصادر محددة وحفظ اللقطة والسجل التدقيقي ذريًا، مع عرض عدادات مصدر البيانات في الواجهة. واكتمل `tenant.assignMember`: الحراسة تتطلب عضوية فعالة وحزمة EXECUTIVE وصلاحية `tenant.manage`، وتمنع إسناد دور للمنفذ نفسه، وتتحقق من المستخدم والدور والنطاق، ثم تكتب العضوية المدعوة وإسناد الدور وسجل التدقيق في معاملة واحدة. ويكملها الآن `tenant.findAssignableUser` الذي يتطلب الحراسة ذاتها، ويبحث بالبريد المطابق فقط، ويعيد حقل الهوية الأدنى لمستخدم غير منضم للمستأجر؛ لا يعرض المستخدم إن كانت له عضوية قائمة. وتعرض واجهة الإدارة اختيارًا صريحًا للمستخدم الناتج قبل تفعيل زر الإسناد، مع رسائل نجاح وخطأ آمنة وتحديث سجل الأعضاء. |
| العمل الجاري | لا توجد كتابة معلقة ضمن دفعة إسناد العضويات؛ الدفعة جاهزة للحفظ بعد اجتياز فحوصات الانحدار. |
| التعريب | طبقة لغة مركزية تضبط `lang` و`dir` وتحفظ الاختيار؛ زر اللغة حاضر في رؤوس الواجهات. تضيف طبقة API رموز أخطاء ورسائل آمنة بالعربية والإنجليزية، وتعرض مساحة العمل وسجل المشاريع وحاسبة EVM الرسالة بحسب اللغة الحالية. |
| الاختبارات الفاشلة | لا توجد؛ نجح 59 اختبارًا ضمن ثمانية ملفات، وفحص TypeScript والبناء الإنتاجي في هذه الدفعة. يغطي اختبار العرض الخادمي نموذج وسجل الإجراءات بالعربية والإنجليزية، وإرشاد غياب المشروع ورسالة حفظ القرار، ونموذج وجدول الأنشطة وحالة النشاط باللغتين، وواجهة اختيار وإسناد عضو قائم مع حالتي النجاح والخطأ. وتغطي اختبارات API لإسناد العضو غياب العضوية الفعالة، وغياب استحقاق EXECUTIVE، ومنع تعديل الامتيازات الذاتية، والسماح بالعضوية والدور وسجل التدقيق ضمن معاملة واحدة؛ وتثبت كذلك أن بحث المستخدم يرفض الوصول قبل قراءة الهوية ويستبعد صاحب العضوية القائمة. |
| المشكلات المثبتة | أصلح توافق تجميع `Set`، وبنية JSX لمساحة العمل، وفحص نطاق WBS العابر للمشروع، وإظهار رسائل الخادم الخام في واجهات التشغيل. |
| العمل المعلق | اختبار تكامل حقيقي لقاعدة البيانات مستقل عن المحاكاة، ودعوات البريد وإدارة إنشاء/تحديث/إلغاء الأدوار والنطاقات، والمستندات وسير العمل، وبقية الوحدات الموضحة في `todo.md`. |
| ترحيلات قاعدة البيانات | `0001_public_gamma_corps.sql` و`0002_violet_scrambler.sql` و`0003_silly_unicorn.sql` مطبقة بنجاح. لا يمكن فرض مشغلي منع تعديل/حذف سجل التدقيق في TiDB Serverless لأن المشغلات غير مدعومة؛ الفجوة موثقة. |
| حالة النشر | النشر التلقائي مفعّل عند كل نقطة تحقق؛ آخر نقطة تحقق منشورة هي `5615300d`. |
| التحقق البصري | فحص المسارات باستخدام مستأجر غير موجود أظهر حالة تحميل أولية فقط ثم رد API متوقع `400 BAD_REQUEST`؛ لذلك لم يُعتمد كدليل للبيانات الحية. تحقق العرض المنضبط تم باختبار خادمي مع بيانات ممررة صراحة، وتبقى مراجعة حساب مستأجر مصرح به مطلوبة عند توفره. |
| الإجراء التالي الدقيق | اختيار الدفعة التالية من خارطة RBAC: تصميم مسار إدارة دور أو نطاق يثبت حراسة المالك ومنع تعديل الامتيازات الذاتية، ثم إضافة دليل اختبار API وواجهة ثنائية اللغة قبل التوسعة. |
