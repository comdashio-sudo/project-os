## نقطة استئناف: محرك الخطط والميزات والترخيص

أضيفت طبقة ترخيص تجارية فوق الاشتراكات الحالية دون تغيير أسماء الحزم الثابتة. يضيف الترحيل `0016_colorful_scarecrow.sql` الخطط والميزات واستحقاقات الخطة ورخص المستأجر وتجاوزات الميزات، بينما يوسع `0017_groovy_sleeper.sql` دورة حالة الاشتراك إلى `trialing` و`active` و`past_due` و`suspended` و`cancelled` و`expired` و`grace_period`. طبقت الترحيلات على قاعدة MySQL/TiDB التشغيلية، وأعيد بناء قاعدة التكامل المنفصلة إلى 47 جدولًا للتحقق من إعادة التطبيق.

يتطلب تفعيل الرخصة وتغيير حالتها وتجاوز ميزتها مسؤول منصة خادميًا، وتعمل هذه العمليات داخل معاملات تحدث الاشتراك واستحقاقات المنتجات والرخصة وسجل التدقيق. يسمح لمسؤول المنصة بقراءة رخصة مستأجر لإدارتها حتى إن لم تتضمن حزمته EXECUTIVE؛ أما المستخدم غير المسؤول فيظل خاضعًا لحارس مسؤول المؤسسة. تربط خدمة Master Plan الآن الميزة النشطة وحد الخطة وحد الكيانات المكانية بمسارات القراءة والإنشاء والإصدار، مع التوافق الخلفي للمستأجرين الذين لا يملكون سجل رخصة جديدًا بعد.

أضيفت صفحة `/licensing/:tenantId` ثنائية اللغة لقراءة الرخصة وإدارة الحد وتغيير الحالة، وتعرض التفعيل أو الترقية فقط عند نجاح عقد كتالوج مسؤول المنصة. لا تستخدم الصفحة `error.message` خامًا. يثبت اختبار DOM تمرير حد `MASTER_PLAN` إلى عقد التجاوز مع معرّف المستأجر والرخصة، ويثبت تكامل tRPC الفعلي دورة التفعيل اليدوي والحد الصفري والتعليق وإعادة التفعيل ورفض قراءة مستأجر آخر لمستخدم غير عضو وسجلات تدقيق الترخيص. اجتازت بوابة `pnpm test && pnpm check && pnpm build && node scripts/run-integration-database-test.mjs` كاملة، بما فيها 30 حالة تكامل فعلية على قاعدة MySQL/TiDB المعزولة.

لا توجد بوابة دفع أو webhook أو بيانات اعتماد Stripe/Tap، ولا تُدعي حدود المقاعد أو المشاريع أو التخزين أو الذكاء أو الاستيراد والتصدير كمنفذة في مسارات الأعمال. تبقى هذه الامتدادات، وإنفاذ انتهاء الرخصة الآلي، مفتوحة وموثقة في `docs/LICENSE_ENGINE.md`.
