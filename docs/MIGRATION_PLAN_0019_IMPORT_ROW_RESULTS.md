# خطة ترحيل 0019 — نتائج صفوف الاستيراد

## الهدف

يضيف الترحيل جدول `data_import_row_results` لتثبيت الأثر القابل للتدقيق لكل صف **صحيح** أثناء تأكيد استيراد WBS أو الميزانية. يحفظ السجل رقم الصف ومفتاح العمل والإجراء المنفذ (`created` أو `updated` أو `skipped`) ومعرّف السجل التشغيلي عند وجوده. لا يحفظ بيانات الملف أو محتواه؛ يبقى الملف في التخزين الكائني ونتائج أخطاء التحقق في `data_import_errors`.

## الكتابة المخططة والأثر المتوقع

| العملية | الأثر المتوقع |
|---|---|
| إنشاء الجدول | جدول جديد فقط، بلا تعديل أو حذف من `data_imports` أو سجلات الأعمال القائمة. |
| مفتاح الاستيراد الخارجي | يربط كل نتيجة بسجل استيراد قائم ويمنع النتيجة اليتيمة. |
| فهرس القراءة | يجعل قراءة النتائج مقيدة بـ`importId` ومرتبة بحسب `rowNumber`. |
| قيد الفرادة | يمنع تكرار نتيجة للصف والإجراء نفسه داخل الاستيراد. |

## استعلام التحقق

```sql
SELECT table_name, table_rows
FROM information_schema.tables
WHERE table_schema = DATABASE()
  AND table_name = 'data_import_row_results';
```

## مسار الاسترجاع

لا ينفذ الحذف تلقائيًا. إذا ثبت فشل وظيفي قبل إصدار نسخة تتضمن بيانات تشغيلية، يعود التطبيق إلى نقطة التحقق السابقة. بعد اعتماد بيانات نتائج فعلية، يتطلب حذف الجدول قرار صيانة صريحًا لأنه يمس دليل التدقيق التشغيلي.
