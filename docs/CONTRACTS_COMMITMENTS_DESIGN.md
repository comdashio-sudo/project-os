# تصميم نواة العقود والالتزامات

## هدف الدفعة

تنشئ هذه الدفعة سجلات تعاقدية ومبالغ التزام مرتبطة بالمشروع، من دون تحويل الالتزام إلى تكلفة فعلية أو تعديل الأرقام المالية المجمعة للمشروع. يظل **العقد** مرجعًا تجاريًا مستقلًا، بينما يمثل **الالتزام** مبلغًا محجوزًا أو متعاقدًا عليه يمكن تتبعه حسب الحالة.

| الكيان | الحدود الإلزامية | الكتابة المسموحة | الدليل الذري |
|---|---|---|---|
| العقد | `tenantId` و`projectId` | مستخدم له حزمة `PROJECT` وصلاحية `project.write` ضمن نطاق المشروع | إدراج العقد وسجل تدقيق في معاملة واحدة |
| الالتزام | `tenantId` و`projectId` و`contractId` اختياري | مستخدم له الحراسة ذاتها؛ يتحقق من ملكية العقد إن وُجد | إدراج الالتزام وسجل تدقيق في معاملة واحدة |
| القراءة | `tenantId` و`projectId` | مستخدم له `project.read` أو نطاق أعلى | لا تعيد سجلًا خارج المستأجر أو المشروع |

## نموذج الحالة

حالات العقد هي `draft` و`active` و`suspended` و`closed` و`cancelled`. حالات الالتزام هي `draft` و`committed` و`released` و`cancelled`. لا تنفذ هذه الدفعة انتقالات حالة أو حذفًا؛ لذلك لا يمكن لإدخال جديد أن يغير حالة سجل قائم أو أن يعدل سجل تدقيق.

## الكتابة المخططة

يضاف جدولا `contracts` و`commitments`. يستخدم كل منهما مفاتيح خارجية للمستأجر والمشروع، مع فهرس قراءة بـ`tenantId, projectId` وفريدة رمز العقد داخل المشروع. يحمل الالتزام `contractId` اختياريًا، لكن خدمة الخادم تتحقق عند وجوده من أنه ينتمي إلى المشروع والمستأجر نفسيهما.

| بند | الأثر المتوقع | استعلام التحقق بعد الترحيل | الاسترجاع |
|---|---|---|---|
| إنشاء جدول العقود | لا تعديل لأي جدول قائم أو بيانات قائمة | `SHOW TABLES LIKE 'contracts'` | حذف الجدول فقط إذا لم تنشأ بيانات إنتاجية |
| إنشاء جدول الالتزامات | لا تعديل لأي جدول قائم أو بيانات قائمة | `SHOW TABLES LIKE 'commitments'` | حذف الجدول فقط إذا لم تنشأ بيانات إنتاجية |
| فهارس القراءة والعزل | تحسن الاستعلامات ولا تغير دلالة السجلات | `SHOW INDEX FROM contracts` و`SHOW INDEX FROM commitments` | حذف الفهرس المسمي عند الضرورة |

## معايير القبول

لا تعتبر الدفعة مكتملة إلا إذا أثبتت الاختبارات رفض مستأجر بلا عضوية، ورفض حزمة PROJECT الغائبة، ورفض عقد خارج المستأجر عند ربط الالتزام، والسماح بالإنشاء المرخّص مع دليل تدقيق داخل المعاملة نفسها. يجب أن تغطي واجهة السجل حالات العربية والإنجليزية والنجاح والخطأ الموطّن، وأن تمر مجموعة الانحدار وفحص النوع والبناء الإنتاجي.
