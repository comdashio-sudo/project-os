# قالب تقرير الدفعة — PROJECT OS

> يستخدم هذا القالب في كل دفعة قابلة للإغلاق. لا يكفي وضع علامة نجاح في أي خانة؛ يجب الإحالة إلى أمر أو اختبار أو مسار ملف قابل لإعادة التشغيل.

| بند بوابة المرجع | الدليل المطلوب | الحالة |
|---|---|---|
| قراءة المرجع | تأكيد قراءة `ENGINEERING_REFERENCE.md` وتحديد القيود ذات الصلة. | غير مكتمل |
| فرض الحالة الصحيحة | وصف نقطة التقارب في الخادم أو قاعدة البيانات وما تمنعه. | غير مكتمل |
| التحقق | الأمر المشغل، عدد الاختبارات، ونتيجة TypeScript والبناء عند انطباقه. | غير مكتمل |
| الرفض والعزل | اختبار يثبت رفض مستأجر أو مشروع أو صلاحية غير صحيحة. | غير مكتمل |
| السماح المشروع | اختبار أو نتيجة تثبت المسار المصرح به دون توسيع صلاحية. | غير مكتمل |
| المسارات الشقيقة | المسارات المتجاورة المفحوصة (قراءة/إنشاء/تحديث/انتقال). | غير مكتمل |
| التعريب | دليل النص العربي والإنجليزي وخريطة الخطأ الآمنة عند وجود واجهة. | غير مكتمل |
| الحدود | ما لم يمكن التحقق منه أو فرضه وسببه وخطة المتابعة. | غير مكتمل |

## سجل التقرير

يُنسخ الجدول المعبأ إلى `PROJECT_STATUS.md` تحت نقطة الاستئناف الخاصة بالدفعة. ويُحدّث `ENGINEERING_COMPLIANCE_AUDIT.md` إذا تغيرت فجوة أو آلية فرض عامة.
