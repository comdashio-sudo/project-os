# سجل التغييرات

## غير منشور

تم إنشاء بيئة مستقلة وتوثيق Phase 0 وسجل العمل الأساسي. أضيفت نواة الشركات والعضويات والأدوار والصلاحيات والاشتراكات والاستحقاقات وسجل التدقيق، مع ترحيلات MySQL واختبارات تفويض تجيب عن العزل والاستحقاق ونطاق الدور. أضيفت جداول المحافظ والمشاريع وWBS والأنشطة والميزانيات والتكاليف والتقدم ولقطات EVM، إضافة إلى المخاطر والقضايا والإجراءات والقرارات ولقطات صحة المشروع. أضيفت واجهة إنشاء مساحة مؤسسية وحاسبة EVM عملية، مع إجراءي إنشاء واستعراض مشروع يفرضان الاستحقاق `PROJECT` وصلاحيات القراءة/الكتابة في الخادم.
