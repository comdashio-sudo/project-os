# خطة ترحيل 0022 — أوامر الشراء

## الهدف

يضيف الترحيل جدول `purchase_orders` لتوثيق أوامر الشراء التشغيلية داخل مشروع معزول. يحمل السجل مفتاح المستأجر والمشروع والمنشئ، ورقم أمر فريد داخل المشروع، واسم المورد، والقيمة والعملة، وتاريخ الأمر، وحالة دورة العمل.

## الأثر المتوقع

| العملية | الأثر المتوقع |
|---|---|
| إنشاء الجدول | إضافة غير هدمية إلى مخطط التشغيل. |
| المفاتيح الخارجية | منع أمر شراء بلا مستأجر أو مشروع أو منشئ صالح. |
| الفريدة | منع رقم أمر مكرر داخل المشروع، مع السماح به في مشروع آخر. |
| الفهرس | تسريع السجل بحسب المشروع والحالة والتاريخ. |

## استعلام التحقق

```sql
SELECT table_name
FROM information_schema.tables
WHERE table_schema = DATABASE()
  AND table_name = 'purchase_orders';
```

## الاسترجاع

لا ينفذ الترحيل حذفًا تلقائيًا. قبل وجود بيانات تشغيلية معتمدة يمكن الرجوع إلى نقطة التحقق السابقة. بعد الاستخدام يتطلب إسقاط الجدول قرار صيانة مستقل لأنه يهدم أثر المشتريات.

## الحدود

لا يربط هذا الإصدار أمر الشراء تلقائيًا بعقد أو التزام أو فاتورة أو مخزون، ولا ينشئ دفعًا خارجيًا. تمثل هذه روابط مالية لاحقة بحراسة نطاق مستقلة.
