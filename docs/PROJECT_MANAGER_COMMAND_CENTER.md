# مركز قيادة مدير المشروع

## الغرض

يوفر المسار `/projects/:tenantId/:projectId/controls` **نقطة التشغيل الموحدة لمدير المشروع**. لا ينشئ هذا المركز صلاحية مستقلة؛ بل يجمع الأدوات والسجلات الموجودة تحت حراسة `PROJECT` وضمن المشروع المحدد، لكي يدير المدير التخطيط والتكلفة والتنفيذ والمشتريات والجودة والمستندات من واجهة منظمة واحدة.

## نطاق الإدارة

لا تظهر البيانات ولا تنفذ الكتابات إلا بعد تحقق `project.read` أو `project.write`، واستيفاء الاستحقاق التجاري `PROJECT`، ومطابقة نطاق العضوية للمشروع أو نطاق أعلى معتمد. لا يمنح المركز وصولًا إلى مشروع شقيق أو إلى إعدادات المستأجر أو إلى أعضاء خارج صلاحية مدير المستأجر.

| مسار العمل | السجلات والأدوات المجمعة |
|---|---|
| البرنامج والتكلفة | WBS، الأنشطة، الميزانية، التكلفة الفعلية، التقدم، لقطات EVM وصحة المشروع. |
| العقود والمشتريات | العقود، الالتزامات، طلبات التوريد، أوامر الشراء، المطالبات والمستندات. |
| الموقع والجودة والموارد | التقارير الميدانية، الجودة، HSE، RFI، NCR، التغييرات، الموارد، المواد والمستودعات. |
| البيانات والمتابعة | استيراد/تصدير Excel المحكوم، Master Plan، الإشعارات، والاستشارة الموسومة بالمصدر. |

## سلوك مركز القيادة

يعرض المركز مؤشرات من مصادر موجودة فقط: لقطة الصحة، CPI/SPI، المتبقي من التدفق النقدي، عدد الأنشطة والأنشطة المتعثرة، وعدد بنود WBS والتقدم. لا يعرض صفرًا بدل مصدر فاشل أو مفقود؛ تبقى حالة المصدر موضعية كما في دليل صلابة اللوحات. تفتح بطاقات المسارات القسم التنفيذي المرتبط بها في الصفحة نفسها، ولا تنشئ رابطًا أو إجراءً خارج الحراسة الخادمية.

## الدليل المطلوب

يثبت اختبار DOM أن المركز يظهر ضمن المشروع المصرح، ويعرض نطاق المشروع، ويفتح مسار المشتريات المقصود. تبقى أدلة MySQL/TiDB وtRPC القائمة مسؤولة عن رفض المشروع العابر والسماح والكتابة والتدقيق لكل سجل عملي داخل المركز.
