# سيناريو العرض نقرة بنقرة (D-16، #177)

عرض واحد على **شركة العرض** المختلقة (`docs/DEMO_COMPANY.md`). المدة 15 دقيقة كحد أقصى.

كل خطوة تذكر ثلاثة أشياء: الشاشة، وما تنقره، وما يجب أن يظهر. وبجانب كل خطوة مقابلها الآلي:
- **رحلة N/فحص** = مثبتة في `pnpm e2e:demo-journey` (`scripts/e2e-demo-journey.mjs`). الرحلة تقرأ الأرقام من الخادم قبل كل خطوة وبعدها وتقارنها بالقوانين.
- **يدوي فقط** = لا تمشيها الرحلة الآلية، فيُتحقق منها بالعين أثناء العرض.

> **قبل العرض (مرة واحدة، المالك):** شركة العرض لا تُبنى على الإنتاج إلا بزر **Demo company ← seed** ببريد المالك (D-36، `BLOCKED_BY_OWNER`).
> لا يُشغَّل أي سكربت أو اختبار على قاعدة الإنتاج (CLAUDE.md §4)؛ فالعرض على الإنتاج يُمشى **يدويًا** بهذا النص، والرحلة الآلية تثبته على قاعدة الاختبار.

## 0. الدخول (دقيقة واحدة) — يدوي فقط
1. افتح المنصة ← «تسجيل الدخول» ← اكتب بريدك ← «إرسال الرمز» ← أدخل الرمز من بريدك (أو كلمة المرور إن عيّنتها).
   - يظهر: «مساحة العمل»، وفي الشريط العلوي مبدّل الشركة على **شركة العرض**.
   - الرحلة الآلية تدخل بجلسات أشخاص العرض الموقّعة، لا برمز البريد.

## 1. لوحة الشركة ومجلس الإدارة (دقيقتان)
2. القائمة ← «المستويات» ← «لوحة الشركة ومجلس الإدارة».
   - يظهر: «الإجماليات» (مشروعان، الربح المتوقع، مشاريع متأخرة)، وصف لكل مشروع في «كل المشاريع»، و«الالتزامات» بالعملة.
   - المقابل: رحلة — الخطوة الأخيرة «the board dashboard shows that project's expected profit» و«the board's page shows no error and no blank».
3. انزل إلى «نسب الإنجاز من المصادر الثلاثة».
   - يظهر: صف لكل مشروع بنسب الموقع والاستشاري والتقرير الشهري والفرقين.
   - **يدوي فقط** (D-6؛ مثبت باختبار القاعدة `pmcPercentagesByProject.database.test.ts` لا بالرحلة).
4. انقر «انتقل إلى مستوى: إدارة المشاريع (المحفظة)».
   - يظهر: مقارنة المشروعين وما ينتظر الاستشاري والجودة.
   - المقابل: رحلة 1 «the portfolio level carries the same profit movement».

## 2. المشروع (دقيقتان)
5. من «كل المشاريع» انقر **PRJ-DEMO-1 · مشروع فلل العرض (500 فيلا)**.
   - يظهر: «التقدم» نحو 16.5%، وCPI نحو 0.96، وSPI نحو 0.88، و«القيمة المكتسبة (EVM)» (PV وEV وAC وEAC وVAC)، و«ربحية المشروع».
   - المقابل: رحلة — «EAC = AC + (BAC − EV)» و«the expected profit = the adjusted contract − EAC».
6. في اللوحة نفسها: «نسب الإنجاز من المصادر الثلاثة» (حسب المنطقة أو البلوك)، ثم «التقرير اليومي» و«التسليمات» و«الفحوصات».
   - **يدوي فقط** للعرض. الأرقام نفسها تقرؤها الرحلة في كل خطوة من `scopes.project`.

## 3. التقرير اليومي ← الاعتماد ← تحرك التقدم (3 دقائق)
7. افتح على الجوال (أو بعرض 390) «الإدخال الميداني» للمشروع ← «التقرير اليومي».
   - املأ «الطقس» و«ملخص اليوم» ← «إضافة عمل» ← «رقم الوحدة» ← النشاط ← «الحالة بعد العمل: مكتمل».
   - انقر «حفظ المسودة» ثم «إرسال للاعتماد».
   - يظهر: «أُرسل التقرير للاعتماد». لا يتحرك أي رقم بعد.
   - المقابل: رحلة 1 «the site engineer's report is in the database, sent for approval» و«…and no level's figure has moved».
8. (سلبي) بحساب كاتب التقرير نفسه انقر «اعتماد».
   - يُرفض: الكاتب لا يعتمد تقريره.
   - المقابل: رحلة 1 «NEGATIVE: the writer cannot approve their own report».
9. بحساب مدير المشروع افتح التقرير ← «ماذا سيتحرك؟».
   - يظهر: «ستتحرك هذه الخلايا».
   - انقر «اعتماد» فيظهر: «اعتُمد التقرير وتحرك التقدم».
   - ارجع إلى لوحة المشروع: التقدم +0.02 نقطة، والقيمة المكتسبة والربح المتوقع ارتفعا بالمقدار نفسه، والتكلفة الفعلية لم تتحرك.
   - المقابل: رحلة 1 — سبعة فحوص من «the report is approved by the project manager» إلى «the company (board) level carries the same profit movement».

## 4. التسليمات والفحص والجودة (3 دقائق)
10. المشروع ← «التسليمات» ← «تسليم جديد» ← «نوع التسليم» ورقمه وعنوانه والاستشاري ← «إنشاء التسليم» ← «إرسال إلى الاستشاري».
    - يظهر: عدد ما ينتظر الاستشاري +1 في المشروع والمحفظة والشركة.
    - المقابل: رحلة 2 «sent: the consultant is now holding one more submittal».
11. (سلبي) بحساب من أرسل التسليم: «تسجيل الرد» ← «حفظ الرد».
    - يُرفض مع السبب على الشاشة.
    - بحساب مدير الجودة: «تسجيل الرد» بالرمز A ← «حفظ الرد»، فيظهر «تم الرد».
    - المقابل: رحلة 2 «NEGATIVE: whoever sent the submittal cannot record its reply» و«replied A».
12. المشروع ← «الجودة» ← «طلب فحص جديد» ← رقم الوحدة ← «إنشاء الطلب» ← «إتمام هذه الخطوة» حتى رد الاستشاري ← A.
    - يظهر: الخلية «مقبولة».
    - المقابل: رحلة 2 «the consultant's answer A is recorded» و«the cell is accepted».
13. (سلبي ثم إيجابي) تبويب «عدم المطابقة (NCR)» ← «إنشاء NCR» على الخلية نفسها.
    - القبول يتوقف عن الاحتساب.
    - حرّك الـNCR مرحلة مرحلة حتى الإغلاق، فيعود القبول.
    - المقابل: رحلة 2 «NEGATIVE: with an NCR open…» و«the NCR is closed» و«closing it restores the acceptance».

## 5. المستودع: صرف ← تكلفة فعلية ← EVM ← الربح (دقيقتان)
14. على الجوال: «الإدخال الميداني» ← «صرف مادة» ← «ابحث بالرمز أو الاسم»: CEM-50 ← الكمية 5 ← «رقم الوحدة» والنشاط ← «حفظ الصرف».
    - يظهر: المخزون ناقص 5 أكياس.
    - التكلفة الفعلية ترتفع بتكلفة الصرف بمتوسط الرف، والقيمة المكتسبة لا تتحرك، وEAC يرتفع، والربح المتوقع ينخفض بالمقدار نفسه في المشروع والمحفظة والشركة.
    - المقابل: رحلة 3 — سبعة فحوص من «the issue is charged at the shelf's average cost» إلى «the stock value at the company level fell by the same cost».
15. القائمة ← «المستويات» ← المشروع ← «انتقل إلى مستوى: المستودع» (أو «إلى المستودع»).
    - يظهر: المواد تحت حد إعادة الطلب.
    - المقابل: رحلة 3 «the warehouse level shows five bags less».

## 6. PMC: الفلل والمتوقفة والماستر بلان (دقيقتان) — يدوي فقط
16. المشروع ← «ضبط المشروع» ← تبويب PMC.
    - يظهر: نسبة كل فيلا ومنطقة وبلوك من جدول الأوزان.
    - ثم «صفحات المشروع» ← «الوحدات المتوقفة»: الفلل بلا حركة أكثر من الحد بأيام العمل، وآخر بند والتالي (Q-14).
17. «التخطيط وملفات البيانات» ← «الرسم التفاعلي للخطة الرئيسية» ← «التلوين حسب» نشاط.
    - يظهر: كل فيلا بلون حالتها مع المفتاح والأعداد (Q-8).
    - **يدوي فقط**: لا تمشيه الرحلة؛ مثبت باختبارات Q-8 وQ-14 في `test:db`.

## 7. التصدير (دقيقة واحدة) — يدوي فقط
18. التقرير اليومي ← «تصدير التقرير» ← PDF أو Word أو Excel العمالة (Q-9).
19. «التقرير الأسبوعي» ← «تصدير» PowerPoint أو PDF (D-50).
20. «سجل المشاريع» ← «حاسبة مدد التطوير» ← تصدير Excel (Q-11).
    - الثلاثة مثبتة باختبارات وحدة ولقطات، لا بالرحلة.

## ما لا يُعرض
| ما لا يُعرض | السبب |
|---|---|
| صور الموقع الحقيقية ورفع الشعارات | تحتاج تخزينًا مضبوطًا (S3/Supabase Storage)؛ بلا تخزين لا تُرفع صور شركة العرض الاثنتا عشرة |
| الخريطة وخلفيتها | مخفية بقرار المالك (CLAUDE.md §5)، وخلفيتها تحتاج التخزين |
| وصول الدعوة أو ملخص الوحدات المتوقفة بالبريد فعليًا | البريد يحتاج إعداد SMTP في الإنتاج (Q-16، `BLOCKED_BY_OWNER`)؛ الإشعار داخل المنصة يعمل |
| الدخول بـGoogle | اختياري وغير مضبوط |
| الدفع والفواتير الضريبية | لا بوابة دفع حقيقية ولا ادعاء امتثال (CLAUDE.md §6) |
| المساعد الذكي (LLM) | خلف مفتاح تشغيل معطّل افتراضيًا |
| الماستر بلان: العناصر الخطية، ولون «التوقف» | لم تُبنَ (حدود Q-8 وQ-14) |
