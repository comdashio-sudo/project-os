# خطة ترحيل 0020 — سجل التقارير الميدانية

## الهدف

يضيف الترحيل جدول `field_reports` لسجل تقارير ميدانية يومية أو تفتيشية أو مرحلية ضمن مشروع محدد. يحمل كل صف مفتاح المستأجر والمشروع، ورقم تقرير فريدًا داخل المشروع، ونوع التقرير، وتاريخ التقرير، وعدد العاملين، وملخصًا، وحالة محكومة، والمنشئ. لا يضيف الترحيل أي ملف أو مرفق؛ تستخدم إدارة المستندات القائمة للمرفقات عند الحاجة.

## الكتابة المخططة والأثر المتوقع

| العملية | الأثر المتوقع |
|---|---|
| إنشاء الجدول | إضافة جدول تشغيلي جديد فقط، بلا تعديل أو حذف من السجلات القائمة. |
| مفاتيح النطاق | مفاتيح خارجية إلى الشركة والمشروع والمستخدم المنشئ تمنع التقرير اليتيم. |
| فريدة الرقم | يمنع رقم التقرير المكرر داخل المشروع، من دون منع الرقم نفسه في مشروع آخر. |
| فهرس القراءة | يسرع قراءة تقرير المشروع بترتيب التاريخ والحالة. |

## استعلام التحقق

```sql
SELECT table_name
FROM information_schema.tables
WHERE table_schema = DATABASE()
  AND table_name = 'field_reports';
```

## مسار الاسترجاع

لا ينفذ حذفًا تلقائيًا. قبل وجود تقارير تشغيلية معتمدة يمكن العودة إلى نقطة التحقق السابقة. بعد ذلك يتطلب حذف الجدول قرار صيانة منفصلًا لأنه يهدم دليلًا تشغيليًا.

## حدود الدفعة

لن يضيف الترحيل إسنادًا تلقائيًا لمهام أو مخاطر أو مستندات، ولا قناة إشعار خارجية. تتطلب تلك الروابط وحدات تالية مع حراسة تقارب مستقلة.
