# خطة ترحيل 0025 — ربط الحوكمة بـRFI وNCR

## الهدف

يوسع الترحيل نوع الهدف في `control_record_links` ليشمل `rfi` و`ncr`. تبقى أنواع المصدر مقيدة بالمخاطر والقضايا والإجراءات والقرارات، لذلك لا يفتح الترحيل مسارًا عامًا غير محكوم بين أي جدولين.

## الضوابط

| القيد | الفرض |
|---|---|
| ملكية RFI وNCR | تعيد الخدمة اختيار الهدف وفق المعرّف والمستأجر والمشروع قبل الإدراج. |
| أنواع المصدر | لا تتغير: `risk` و`issue` و`action` و`decision`. |
| أنواع الهدف | الأنواع الأربعة السابقة إضافة إلى `rfi` و`ncr` فقط. |
| منع الذات والتكرار | يستمر المنع الخادمي والفهرس الفريد الحالي. |

## الأثر والاسترجاع

يعدل الترحيل تعداد `targetType` فقط دون فقد بيانات أو تعديل سجل قائم. الاسترجاع يتطلب إزالة أي روابط تستعمل `rfi` أو `ncr` قبل إعادة التعداد إلى النسخة السابقة، ولذلك لا ينفذ بلا نافذة صيانة معتمدة.

## استعلام التحقق

```sql
SHOW COLUMNS FROM control_record_links LIKE 'targetType';
```
