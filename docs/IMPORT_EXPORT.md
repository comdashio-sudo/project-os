# محرك الاستيراد والتصدير الموحد

## نطاق النواة

يقدم PROJECT OS خدمة بيانات مشتركة بدل منطق رفع مكرر داخل الوحدات. تبدأ النواة بوحدتي **WBS** و**الميزانية**، ثم تتوسع إلى الأنشطة والتقدم والتكلفة والموارد والسجلات التجارية. تقبل خدمة التحليل ملفات `XLSX` و`CSV` فقط، وتحفظ الملف الأصلي في التخزين الكائني مع مفتاحه وبصمته في السجل؛ لا تخزن بايتات الملف في قاعدة البيانات.

| مرحلة | الضابط الخادمي |
|---|---|
| اختيار القالب والمشروع | استحقاق PROJECT وصلاحية القراءة أو الكتابة ونطاق المشروع. |
| التحليل والتعيين | لا يعيّن الحقول منخفضة الثقة تلقائيًا؛ يطبع العناوين العربية والإنجليزية ويعيد تعيين الحقول فقط عند تطابق معروف. |
| التحقق والمعاينة | يتحقق من نوع الملف والحقول الإلزامية والقيم الرقمية غير السالبة لكل صف؛ لا تعرض خطوة التأكيد عند وجود خطأ. |
| التأكيد والاستيراد | يعيد تنزيل الملف الأصلي بمفتاح التخزين، ويتحقق من بصمة SHA-256 والنطاق وقابلية التأكيد والتكرار، ثم يكتب سجلات WBS أو الميزانية وتحديث السجل وسجل تدقيق واحد داخل معاملة. |
| التصدير | يجلب المصدر المحمي نفسه ثم يصدّر فقط الأعمدة والصفوف المصرح بها. |

## سجل التشغيل

يحفظ سجل الاستيراد معرفه والمستأجر والمشروع عند وجوده والوحدة والقالب واسم الملف والمفتاح والبصمة والحالة والعدادات والنتائج المختصرة والمنشئ والمدة. تحفظ أخطاء الصفوف منفصلة، ولا تنفذ قيمة ملف مباشرة كمعرّف مشروع أو WBS دون حلها ضمن المستأجر والمشروع.

يقبل التأكيد في الدفعة الحالية السجل ذي الحالة `validated` فقط، ويكتب العناصر بنمط `fail_on_duplicate`. يرفض التكرار داخل الملف أو التكرار الموجود مسبقًا ضمن المشروع قبل بداية المعاملة. بعد النجاح تتحول الحالة إلى `completed` مع عداد السجلات المنشأة ووقتَي البداية والإكمال، ويظهر سجل آخر العمليات في واجهة Level 3 بالعربية والإنجليزية. لا تتجاوز آلية التأكيد أي ملف أو صف أو مشروع غير مصرح به.

## التصدير المنفذ

يدعم المسار `dataImports.export` وحدات **WBS** و**الميزانية** و**الأنشطة** بصيغتي `XLSX` و`CSV`. يفرض عضوية المستأجر واستحقاق `PROJECT` وصلاحية `project.read` ونطاق المشروع قبل قراءة أي سجل. ينتقي الاستعلام أعمدة القالب فقط ولا يعيد مفاتيح المستأجر أو معرفات العلاقات أو حقول التدقيق. ينشئ المولد رؤوسًا عربية أو إنجليزية وفق لغة الواجهة، ويعيد البيانات مشفرة Base64 للتنزيل المباشر في المتصفح ثم يسجل حدث `data_export_generated` في معاملة منفصلة.

## حدود الدفعة الأولى

لا تنفذ الدفعة الأولى معالجة دفقية قابلة للاستئناف للملفات الضخمة أو تراجعًا عامًا للكتابات التجارية. هذه امتدادات لاحقة تتطلب سجل تغييرات على مستوى الصف. تبقى قيود الحزمة وعدد الاستيراد/التصدير قابلة للضبط في الاستحقاقات ولا تُثبت في الواجهة.
