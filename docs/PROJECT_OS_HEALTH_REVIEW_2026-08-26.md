## 3. الوظائف المثبتة

تعمل عزل المستأجر والمشروع، RBAC والاستحقاق، مستويات EXECUTIVE وPMO وPROJECT، EVM وصحة المشروع، المواد والمستودعات والمشتريات، سجل الموظفين والرواتب وتوزيع التكلفة، الاستيراد المحكوم للـExcel وXER، المستندات والجودة وRFI/NCR/HSE، والدعم المحكوم. لا تقوم الواجهة بتعويض الحراسة الخادمية؛ كل مسارات الأعمال تبقى مقيدة بالخادم وسجل التدقيق.

السلسلة التجارية منفذة ومثبتة: BOQ مرتبط بالتوريد والالتزامات، ثم عقود الباطن والمستخلصات وفواتير المشروع. الواجهة `CommercialChain` ثنائية اللغة وتغطي حالات التحميل والفراغ والخطأ. شاشة FPAC تعرض قيمة BOQ ونسب الفوترة والتكلفة ومؤشرات مصدرها موثق؛ الفرق بين المفوتر والتكلفة **مؤشر تشغيلي تقريبي** وليس ربحًا محاسبيًا نهائيًا.

الفوترة المنظمة منفذة ضمن حدودها: VAT حسابي 15%، رقم فاتورة متسلسل، وموفرا Manual وMock وفاتورة JSON منظمة. يثبت التكامل الحي إنشاء مساحة تجريبية، رفض وصول فوترة عابر، إصدار فاتورة VAT، وطلب/تأكيد دفع يدوي ودورات Mock. لا يوجد ادعاء بوابة دفع حقيقية أو توافق ZATCA أو PDF-A3/XML نظامي.
