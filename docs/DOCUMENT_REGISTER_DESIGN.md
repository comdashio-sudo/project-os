# تصميم نواة سجل المستندات والإصدارات

تؤسس هذه الدفعة سجل مستندات مرتبطًا بالمشروع، وإصدارات غير قابلة للاستبدال، مع حفظ بايتات الملف في التخزين الكائني فقط. لا تخزن قاعدة البيانات أي محتوى ملف أو رابط يدخله العميل؛ تحفظ المفتاح الذي ينشئه الخادم بعد الرفع وتفاصيل النسخة القابلة للتدقيق.

| الكيان | حدود الملكية | حقيقة غير قابلة للتعديل | قاعدة الوصول |
|---|---|---|---|
| سجل المستند | مستأجر + مشروع | الرقم والعنوان والحالة المرجعية | `PROJECT` و`project.read` للقراءة، و`project.write` للإنشاء |
| إصدار مستند | مستأجر + مشروع + مستند | رقم إصدار متزايد ومفتاح تخزين يولده الخادم وبصمة المحتوى | الكتابة مقيّدة بالمشروع نفسه؛ لا يستبدل إصدارًا قائمًا |
| الملف | تخزين كائني | البايتات خارج قاعدة البيانات | يرفع الخادم المحتوى ثم يحتفظ بالمفتاح عند اكتمال السجل |

## تسلسل الكتابة والأثر

يرسل العميل البيانات الوصفية ومحتوى الملف بترميز Base64 ضمن حد 10 ميغابايت للبايتات بعد فك الترميز. يتحقق الخادم من النوع والحجم والتمثيل قبل الرفع، ثم ينشئ مفتاح التخزين من المستأجر والمشروع ومعرف إصدار عشوائي. لا يثق الخادم في أي مفتاح أو رابط يرسله العميل.

بعد رفع الملف، تكتب معاملة واحدة سجل المستند أو الإصدار وسجل التدقيق. إذا أخفقت المعاملة، يبقى الملف غير مشار إليه بالمفتاح العشوائي، ولا تنشأ له مراجع في قاعدة البيانات. لا تنفذ هذه الدفعة حذف الملف لأن خدمة التخزين لا توفر حذفًا؛ الإزالة المنطقية لسجل نسخة مؤجلة لوحدة الحوكمة.

| التغيير المخطط | الأثر المتوقع | التحقق | الاسترجاع |
|---|---|---|---|
| جدول `project_documents` | سجل مستندات معزول بالمستأجر والمشروع | فحص وجود الجدول والفهارس | حذف الجدول فقط قبل وجود بيانات إنتاجية |
| جدول `document_versions` | إصدارات ومفاتيح تخزين فقط، بلا BLOB | فحص وجود الجدول والفريدة حسب المستند والإصدار | حذف الجدول فقط قبل وجود بيانات إنتاجية |
| رفع إصدار | تخزين كائني ثم مرجع ذري وسجل تدقيق | اختبار التفويض وعَدّ إدراجين في المعاملة | لا رابط قاعدة بيانات عند فشل المعاملة |

## معايير القبول

يجب إثبات رفض غياب العضوية والاستحقاق ونطاق مشروع عابر، والسماح بإنشاء سجل مستند وإصدار أول مع تدقيق ذري. يثبت اختبار واجهة ثنائي اللغة عرض السجل وحالات النجاح والخطأ الآمنة؛ ولا يظهر أي رابط أو مفتاح خام لا يملكه المشروع.
