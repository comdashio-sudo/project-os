# الملاحة المؤسسية الديناميكية

## قرار التنفيذ

تعيد واجهة `navigation.get` عناصر مسموح بها حُسبت في الخادم من لقطة عضوية المستأجر والاستحقاقات والصلاحيات والنطاق. لا تحتوي الواجهة على قائمة صلاحيات بديلة، ولا تعرض روابط لمسارات غير منفذة. لا يُعامل إخفاء الرابط كضابط أمان؛ تبقى حراسة كل صفحة وإجراء خادميًا مستقلة.

| عنصر حي | المنتج والصلاحية | النطاق المطلوب | المسار |
|---|---|---|---|
| لوحة القيادة التنفيذية | `EXECUTIVE` + `executive.read` | الشركة | `/executive/:tenantId` |
| لوحة PMO | `PMO` + `pmo.read` | الشركة | `/pmo/:tenantId` |
| سجل المشاريع | `PROJECT` + `project.read` | الشركة | `/projects/:tenantId` |
| ضوابط المشروع | `PROJECT` + `project.read` | المشروع | `/projects/:tenantId/:projectId/controls` |
| إدارة المؤسسة | `EXECUTIVE` + `tenant.manage` | الشركة | `/tenants/:tenantId/administration` |

## الواجهة والتعريب

يوفر `EnterpriseNavigation` سياقًا مرئيًا لاسم المستوى، ورابط رجوع، وروابط العناصر المحسوبة خادميًا. دُمج في لوحات **EXECUTIVE** و**PMO** و**PROJECT**، وفي سجل المشاريع وإدارة المؤسسة. تُعرّب عناصر السياق والروابط للعربية والإنجليزية، وتستفيد من اتجاه التطبيق الحالي RTL/LTR.

## أدلة التحقق

| الدليل | النتيجة |
|---|---|
| اختبار نطاق المجال | المستخدم ذو النطاق المشروع لا يرى سجل الشركة ولا مشروعًا آخر. |
| اختبار tRPC بقاعدة MySQL/TiDB معزولة | أُعيدت العناصر المرخصة للمستخدم المصرح، ورُفض سياق مشروع مستأجر آخر. |
| اختبار DOM | ظهرت وصلة ضوابط المشروع المحسوبة فقط ضمن سياق عربي؛ لم تظهر وصلة PMO المفترضة. |
| بوابة الجودة | `pnpm test && pnpm check && pnpm build && node scripts/run-integration-database-test.mjs` اجتازت بنجاح. |

## الحدود المفتوحة

المواصفة الأوسع تطلب بحثًا ومساعدة وقائمة مستخدم وإشعارات وتقدّمًا للأمام وسياقات وحدات أكثر تفصيلًا. لم تُنشأ روابط وهمية لهذه القدرات؛ ستضاف عند توفر مساراتها وحراساتها الخادمية واختباراتها.
