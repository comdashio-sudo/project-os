# الملاحة المؤسسية الديناميكية

## قرار التنفيذ

تعيد واجهة `navigation.get` عناصر مسموح بها حُسبت في الخادم من لقطة عضوية المستأجر والاستحقاقات والصلاحيات والنطاق. لا تحتوي الواجهة على قائمة صلاحيات بديلة، ولا تعرض روابط لمسارات غير منفذة. لا يُعامل إخفاء الرابط كضابط أمان؛ تبقى حراسة كل صفحة وإجراء خادميًا مستقلة.

| عنصر حي | المنتج والصلاحية | النطاق المطلوب | المسار |
|---|---|---|---|
| لوحة القيادة التنفيذية | `EXECUTIVE` + `executive.read` | الشركة | `/executive/:tenantId` |
| لوحة PMO | `PMO` + `pmo.read` | الشركة | `/pmo/:tenantId` |
| سجل المشاريع | `PROJECT` + `project.read` | الشركة | `/projects/:tenantId` |
| ضوابط المشروع | `PROJECT` + `project.read` | المشروع | `/projects/:tenantId/:projectId/controls` |
| إدارة المؤسسة | `EXECUTIVE` + `tenant.manage` | الشركة | `/tenants/:tenantId/administration` |

## الواجهة والتعريب

يوفر `EnterpriseNavigation` شريطًا مؤسسيًا موحدًا يضم الرجوع والتقدم، ومسارًا قابلًا للقراءة من مساحة العمل إلى سياق الصفحة، وروابط العناصر المحسوبة خادميًا. يضع الشريط قائمة المستخدم المرتبطة بجلسة OAuth وإجراء تسجيل الخروج القائم، وقائمة إشعارات داخلية تقرأ فقط إشعارات المستلم في المستأجر الحالي، تعرض عداد غير المقروء، وتستدعي عقد الإقرار الخادمي. لا يُنشئ الشريط روابط أو بيانات محلية بديلة. دُمج في لوحات **EXECUTIVE** و**PMO** و**PROJECT**، وفي سجل المشاريع وإدارة المؤسسة. تُعرّب عناصر السياق والروابط والقوائم للعربية والإنجليزية، وتستفيد من اتجاه التطبيق الحالي RTL/LTR.

## أدلة التحقق

| الدليل | النتيجة |
|---|---|
| اختبار نطاق المجال | المستخدم ذو النطاق المشروع لا يرى سجل الشركة ولا مشروعًا آخر. |
| اختبار tRPC بقاعدة MySQL/TiDB معزولة | أُعيدت العناصر المرخصة للمستخدم المصرح، ورُفض سياق مشروع مستأجر آخر. |
| اختبار DOM | ظهرت وصلة ضوابط المشروع المحسوبة فقط ضمن سياق عربي؛ لم تظهر وصلة PMO المفترضة. يثبت الاختبار أيضًا ترتيب التركيز: رجوع، تقدم، مساحة العمل، الإشعارات، المستخدم، ثم روابط الوحدات. |
| قائمة المستخدم | تفتح بيانات الجلسة وتفوض زر الخروج إلى `useAuth().logout()`؛ لا تنشئ مسار خروج بديلًا. |
| الإشعارات | تظهر الإشعارات غير المقرّة فقط من `notifications.list` وتستدعي `notifications.acknowledge` بالمعرّف والمستأجر، بينما يثبت تكامل MySQL/TiDB عزل المستلم وتدقيق الإقرار. |
| بوابة الجودة | اجتاز `pnpm coverage:trpc && pnpm test && pnpm check && pnpm build && node scripts/run-integration-database-test.mjs`: 232 اختبار وحدة وواجهة و50 تكامل حي. |

## الحدود المفتوحة

المواصفة الأوسع تطلب شريطًا جانبيًا عامًا وبحثًا ومساعدة وإعدادات وسياقات وحدات أكثر تفصيلًا. اكتملت قائمة المستخدم والإشعارات والتقدم، لكن لم تُنشأ روابط وهمية لبقية القدرات؛ ستضاف عند توفر مساراتها وحراساتها الخادمية واختباراتها.
