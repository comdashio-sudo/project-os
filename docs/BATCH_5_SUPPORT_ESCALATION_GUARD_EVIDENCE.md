# دليل الدفعة 5 — حارس تصعيد الرد الآلي

**الحالة:** `PROVEN` محليًا قبل الالتزام والدفع إلى `github/main`.

راجعت الدفعة مسار الدعم القائم واكتشفت أن تعليمات النموذج وحدها كانت تطلب عدم تقديم أسعار أو وعود أو مواعيد، لكنها لم تكن **حارسًا خادميًا** مستقلًا. أضيف حارس حتمي يفحص نص طلب العميل، وكذلك النص المقترح من الرد، ويمنع الإرسال المعرفي ويُبقي رد التصعيد المحافظ عند طلب أو عرض سعر أو استرداد أو تعويض أو موعد إصلاح أو SLA أو التزام تعاقدي أو ضمان.

| الضابط | الأثر المثبت |
|---|---|
| طلب محظور | `requiresMandatoryHumanEscalation` يتعرف على المصطلحات العربية والإنجليزية للأسعار والاسترداد والتعويض والمواعيد وSLA والالتزامات والضمانات. |
| رد مقترح محظور | لا يقبل المسار ردًا مقترحًا يتضمن مصطلح التزام محظورًا، حتى إن جاءت جميع إحالاته من مقالات معرفة مصرح بها. |
| تصعيد محافظ | يبقى الرد الافتراضي: «A support specialist will review this request.»، مع `shouldEscalate=true` وتحديث حالة تصعيد التذكرة وسجل دعم/تدقيق ذريين. |
| معرفة معتمدة | لا يقبل المدقق ردًا إلا إذا كانت كل إحالاته في قائمة المقالات المنشورة داخل المستأجر. |
| العزل | قراءة التذاكر، والرد، والمقالات، والمصادر تبقى مقيدة بالمستأجر وبمالك التذكرة أو مديرها، ويثبت مشغل التكامل رفض الوصول العابر والتصعيد المدقق. |

## حدود معلنة

لا يستدعي دليل الاختبار نموذجًا خارجيًا ببيانات عميل. الحارس الخادمي يفرض التصعيد للأنواع المحظورة سواء أتاح النموذج ردًا أم لا. يبقى البريد الخارجي `BLOCKED_BY_OWNER`، وتبقى شروط الخدمة وسياسة الاسترداد والأسعار الفعلية قرارات مالك؛ فلا يستخدم الحارس هذه القيم أو يخترعها.
