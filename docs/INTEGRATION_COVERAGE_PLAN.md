# خطة توسيع اختبار التكامل التشغيلي

تغطي قاعدة `project_os_integration_test` حاليًا HSE وNCR وRFI والقضايا والعقود والالتزامات والموارد والمطالبات والمستندات وإنشاء نسخها وطلبات التغيير والإشعارات والتدفق النقدي التنفيذي والتخطيط والميزانية وEVM وصحة المشروع والاستيراد والتصدير والتقارير الميدانية وفحوصات الجودة وأوامر الشراء وروابط الحوكمة وإدارة العضويات والأدوار ودعوات المستأجر وإنشاء المستأجر وقراءة المالك وإنشاء المشروع ودورة حياته وانتقالات التغيير وHSE وحفظ لقطة EVM اليدوية وقراءات الغلاف التشغيلية. تثبت الحالات الرفض العابر والسماح والتدقيق في السجلات التي يغطيها المشغل. سجّل آخر تشغيل موثق **50 حالة تكامل tRPC فعلية**.

| الأولوية التالية | حالة الدليل الحالي | الإجراء المطلوب |
|---|---|---|
| الالتزامات | دليل tRPC فعلي متحقق. | رُفض مشروع مستأجر آخر، وأُنشئ التزام مشروع مصرح به بسجل تدقيق واحد ثم نُظفت بياناته داخل الحالة. |
| قرارات القيادة | دليل tRPC فعلي متحقق للإنشاء. | رُفض المشروع العابر، وأنشئ قرار مشروع مصرح به بسجل تدقيق واحد ثم نُظفت بياناته داخل الحالة؛ تبقى القراءة ضمن اختبار لوحة القيادة. |
| المحافظ والبرامج | دليل tRPC فعلي متحقق. | رُفض ربط محفظة عابرة، ثم أنشئت محفظة وبرنامج وربط مشروع مصرح مع 3 سجلات تدقيق وتنظيف كامل. |
| المخاطر والإجراءات والتصعيدات | دليل tRPC فعلي متحقق. | رُفضت كتابات خطر وإجراء عابرة، وأنشئت سجلات المشروع المصرح بها مع سجلين تدقيقيين؛ كما رُفضت التصعيدات العابرة وأثبتت انتقالات `none → pending → escalated` المؤهلة مع ستة سجلات تدقيق وتنظيف داخلي. |
| المستشار الذكي | اختبار DOM وفحص نموذج حي ودليل رفض tRPC فعلي. | يرفض التكامل مشروع مستأجر آخر بعد منح `project.read` وقبل أي استدعاء نموذج؛ يبقى اختبار النصيحة المصرح بها طرفيًا لتجنب تكلفة نموذج في كل انحدار. |
| التخطيط WBS والأنشطة والتقدم | دليل tRPC فعلي متحقق. | رُفض إنشاء WBS لمشروع عابر، وأنشئ WBS ونشاط وتقدم للمشروع المصرح بثلاثة سجلات تدقيق وتنظيف داخلي. |
| الميزانية والتكاليف | دليل tRPC فعلي متحقق. | رُفضت كتابة ميزانية وتكلفة عابرتان، وأنشئت الميزانية والتكلفة للمشروع المصرح بسجلين تدقيقيين وتنظيف داخلي. |
| التقاط EVM وصحة المشروع | دليل tRPC فعلي متحقق. | رُفض التقاط EVM والصحة لمشروع مستأجر آخر قبل الكتابة، ثم أُنشئت لقطتا المشروع المصرح وسجلا تدقيق وتُنظف السجلات داخليًا. |
| تحليل الاستيراد والتصدير | دليل tRPC فعلي متحقق. | رُفض تحليل ملف WBS لمشروع مستأجر آخر قبل الوصول للتخزين الكائني أو إنشاء سجل `data_imports` أو سجل تدقيق. كما رُفض تصدير مشروع عابر، ثم صُدّر CSV مصرح احتوى صف WBS تجريبيًا وكتب سجل `data_export_generated` واحدًا. ويفك التكامل XLSX عربيًا لـWBS، كما يثبت CSV إنجليزيًا للميزانية وXLSX عربيًا للأنشطة مع محتوى الصفوف وسجلَي تدقيق. لا تبقى تنويعة تصدير مسجلة غير مثبَتة؛ يظل التوسع المستقبلي مشروطًا بدليل رفض وسماح وتنظيف مكافئ. |

لا تغلق هذه الخطة فجوة مشغلات `audit_logs` في TiDB Serverless؛ تظل تلك فجوة بيئية موثقة تتطلب MySQL/InnoDB أو حساب تشغيل محدود لإغلاقها على مستوى قاعدة البيانات.
